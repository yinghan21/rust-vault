# std::f32

> [!abstract] 一句话
> `std::f32` 主要不是「函数库」，而是一组描述 `f32` 表示范围与精度的常量，外加 `std::f32::consts` 里的 π、e 等数学常量。

## 模块简介

这个模块的内容只有常量。它服务于 [[primitive.浮点类型|Type f32]]：告诉你在 IEEE 754 单精度下，能表示的最大值、最小值、机器精度、十进制有效位数分别是多少。数值运算（`sqrt`、`sin`、`powi`、`round`）本身是 `f32` 原始类型上的**固有方法**，不在这个模块里。

从 Rust 1.43 起，这些常量被复制到了 `f32` 类型的关联常量上（`f32::MAX`、`f32::EPSILON`），模块级写法 `std::f32::MAX` 已被标记为 `deprecated`，编译时会出现警告。新代码统一写 `f32::MAX`，这样泛型里也能直接通过类型参数访问。

真正天天用的是子模块 `std::f32::consts`：`PI`、`E`、`SQRT_2`、`LN_2`、`FRAC_PI_2` 等。它们没有对应的关联常量，只能从这个子模块取。

## 快速上手

```rust
fn main() {
    // 表示方式与精度：基数、二进制位数、十进制有效位数
    assert_eq!(f32::RADIX, 2);
    assert_eq!(f32::MANTISSA_DIGITS, 24);
    assert_eq!(f32::DIGITS, 6); // 十进制只有约 6 位可靠数字

    // 取值范围与精度
    println!("MAX          = {:e}", f32::MAX);          // 3.4028235e38
    println!("MIN_POSITIVE = {:e}", f32::MIN_POSITIVE); // 1.1754944e-38
    println!("EPSILON      = {:e}", f32::EPSILON);      // 1.1920929e-7
    println!("2 的指数范围  = {}..={}", f32::MIN_EXP, f32::MAX_EXP);
    println!("10 的指数范围 = {}..={}", f32::MIN_10_EXP, f32::MAX_10_EXP);

    // 无穷与非数字
    assert!(f32::INFINITY > f32::MAX);
    assert!(f32::NEG_INFINITY < f32::MIN);
    assert_eq!(1.0f32 / 0.0, f32::INFINITY);
    assert!((0.0f32 / 0.0).is_nan()); // NaN 不等于任何值，只能用 is_nan 判断

    // 机器精度：1.0 与它的下一个可表示值只差 EPSILON
    assert_eq!(1.0f32 + f32::EPSILON, 1.000_000_1);

    // 子模块 consts 提供数学常量
    let r = 2.0f32;
    let area = std::f32::consts::PI * r * r;
    assert!((area - 12.566_371).abs() < 1e-4);

    // 0.1 在二进制浮点里无法精确表示，累加会积攒误差
    let sum: f32 = (0..10).map(|_| 0.1f32).sum();
    assert!((sum - 1.0).abs() < 1e-6);
    println!("0.1 累加十次 = {sum}");
}
```

## 常用条目

| 条目 | 说明 |
| --- | --- |
| `std::f32::MAX` | 最大有限值，约 `3.40e38`；推荐写 `f32::MAX`。 |
| `std::f32::MIN` | 最小有限值（负数），约 `-3.40e38`。 |
| `std::f32::MIN_POSITIVE` | 最小正**规格化**值，约 `1.18e-38`。 |
| `std::f32::EPSILON` | 机器精度 ε，约 `1.19e-7`，用于浮点比较的容差。 |
| `std::f32::INFINITY` | 正无穷，`1.0 / 0.0` 得到它。 |
| `std::f32::NEG_INFINITY` | 负无穷。 |
| `std::f32::NAN` | 非数字，任何比较都返回 `false`。 |
| `std::f32::RADIX` | 内部表示的基数，恒为 `2`。 |
| `std::f32::MANTISSA_DIGITS` | 二进制有效位数，`24`。 |
| `std::f32::DIGITS` | 十进制有效位数，`6`。 |
| `std::f32::MIN_EXP` / `MAX_EXP` | 二进制指数下界加一 `-125` / 上界 `128`。 |
| `std::f32::MIN_10_EXP` / `MAX_10_EXP` | 十进制指数下界 `-37` / 上界 `38`。 |
| `std::f32::consts` | 数学常量子模块：`PI`、`E`、`SQRT_2`、`FRAC_PI_2` 等。 |
| `std::f32::consts::PI` | 圆周率，单精度近似值。 |

## 注意事项

> [!warning] 模块级常量已被标记为 `deprecated`
> `std::f32::MAX` 这类路径仍能编译，但会报 `deprecated` 警告，官方建议改用 `f32::MAX`。两条路径取到的是同一个值，混用只会让代码显得旧。子模块 `std::f32::consts` 不在此列，它没有关联常量替代品。

> [!tip] `f32` 只有约 7 位有效数字
> `f32` 的 `DIGITS` 是 `6`（保守的十进制保证位数），实际能可靠还原的约 7 位。它比 `f64` 省一半内存、在 SIMD 和图形计算里更快，但不适合金额、坐标累积、长时间求和的场景——误差会肉眼可见。

> [!danger] 浮点比较的三个坑
> - 用 `==` 比较两个计算结果是错的，应比较差值是否小于 `EPSILON` 或业务容差。
> - `NAN` 与任何值（包括自己）比较都为 `false`，判断要用 `is_nan()` 或 `is_finite()`。
> - `MIN` 是「最小有限值」而不是「最小正值」，最小正数看 `MIN_POSITIVE`。
