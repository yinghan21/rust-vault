# std::u128

> [!abstract] 一句话
> `std::u128` 是 128 位无符号整数的「常量模块」：只有 `MIN`、`MAX` 两个常量，官方已建议改用原始类型上的关联常量。

## 模块简介

`std::u128` 是个**冗余模块**：它不定义类型，只把 `u128` 的取值边界挂成模块路径 `std::u128::MIN` / `std::u128::MAX`。这两个常量已被标注「未来版本弃用」，现在引用只报 `deprecated` 警告；新代码直接写 `u128::MIN` / `u128::MAX`。`u128` 类型本身是 Rust 1.26 才稳定的，所以这个模块的稳定版本比同系列的 `u8` / `u64` 晚得多。

**整数的方法不在这个模块里。** 溢出检查、进制解析、位运算、字节序转换全部定义在原始类型 `u128` 上，属于[[primitive.整数类型|整数类型]]页面的内容 —— 例如 `u128::checked_mul`、`u128::from_str_radix`、`u128::to_be_bytes`。位宽 `BITS` 也只在原始类型上有。所以本页只讲那两个常量，其余请移步该页。

`u128` 占 16 字节、按 16 字节对齐，范围到约 `3.4e38`。它最实在的用途是**兜底不溢出**：两个 `u64` 相乘、`Duration::as_nanos` 给出的纳秒总量、128 位的 UUID 与 IPv6 地址、编译器与加密实现里的中间量。代价是 64 位 CPU 上没有单条 128 位指令，加减乘除要靠两半拼出来，通常明显比 `u64` 慢，热路径里不要随手加宽。

## 快速上手

```rust
use std::time::Duration;

fn main() {
    #[allow(deprecated)]
    let legacy_max = std::u128::MAX;
    assert_eq!(legacy_max, 340_282_366_920_938_463_463_374_607_431_768_211_455);

    assert_eq!(u128::MIN, 0);
    assert_eq!(u128::BITS, 128);
    assert_eq!(std::mem::size_of::<u128>(), 16);

    // 128 位正好放得下两个 u64 拼起来的 ID
    let id = (1u128 << 64) | u64::MAX as u128;
    assert_eq!(id.to_be_bytes().len(), 16);
    assert_eq!(u128::from(u64::MAX), u64::MAX as u128);

    // 纳秒级时长用 u128 承载，避免 u64 溢出
    let nanos: u128 = Duration::from_secs(2).as_nanos();
    assert_eq!(nanos, 2_000_000_000);

    // 两个 u64 相乘在 128 位里不会溢出
    let prod = u64::MAX as u128 * u64::MAX as u128;
    assert_eq!(prod, 340_282_366_920_938_463_426_481_119_284_349_108_225);

    println!("u128 范围 = {} ..= {}", u128::MIN, u128::MAX);
}
```

## 常用条目

| 条目 | 说明 |
| --- | --- |
| `std::u128::MIN` | 最小值 `0`，模块路径已标记为待弃用。 |
| `std::u128::MAX` | 最大值约 `3.4e38`，模块路径已标记为待弃用。 |
| `u128::MIN` / `u128::MAX` | 推荐写法：原始类型上的取值边界。 |
| `u128::BITS` | 位宽，恒为 `128u32`；模块里没有这个常量。 |
| `u128::from(u64)` | 无符号加宽，编译期就能保证不失败。 |
| `u64::try_from(u128)` | 收窄回 `u64`，越界返回 `Err`。 |
| `u128::to_be_bytes` / `from_be_bytes` | 与十六字节大端数组互转，UUID / IPv6 常用。 |
| `u128::to_le_bytes` / `from_le_bytes` | 小端版本，适配二进制文件格式。 |
| `u128::from_str_radix` | 解析大数的十六进制或其它进制。 |
| `u128::checked_add` / `checked_mul` | 溢出时返回 `None`。 |
| `u128::wrapping_mul` | 溢出时按模 2¹²⁸ 回绕。 |
| `u128::count_ones` / `leading_zeros` | 位计数与前导零，可反推有效位宽。 |
| `u128::swap_bytes` | 反转十六个字节的顺序。 |
| `u128::pow` | 整数幂，底数超过 `u64` 时用它。 |

## 注意事项

> [!warning] 模块常量行将弃用
> `std::u128::MIN` / `std::u128::MAX` 会触发 `deprecated` 警告，官方计划在未来版本移除。新代码写 `u128::MIN` / `u128::MAX`；模块里同样没有 `BITS`。

> [!danger] 慢，而且占对齐
> `u128` 在 64 位平台上通常没有单条机器指令，乘除尤其慢；结构体里放一个 `u128` 会把对齐要求提到 16 字节，和 `u64` / `u32` 混排容易浪费空间。热路径上如果只需要「两个 `u64` 不溢出」，用 `u64::checked_*` 或 `u128` 仅在最后一步转换往往更快。

> [!tip] `u128` 一样会溢出
> 它只是更宽，不是不会溢出；`as` 转换也照样静默截断（`u128 as u64` 取低 64 位）。要检测就 `u64::try_from`。写大常量时每三位加下划线，并带上 `u128` 后缀，否则编译器可能按 `u64` 推导后报字面量越界。
