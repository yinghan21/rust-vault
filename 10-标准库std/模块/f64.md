# std::f64

> [!abstract] 一句话
> `std::f64` 提供 `f64` 的表示范围与精度常量，外加 `std::f64::consts` 里的 π、e 等数学常量；真正的浮点运算方法在 `f64` 原始类型上。

## 模块简介

`f64` 是 Rust 的默认浮点类型：不带后缀的小数字面量（`1.5`、`3.0`）默认就是 `f64`。它对应 IEEE 754 双精度——64 位、53 位有效二进制位、十进制约 15~17 位有效数字，与 C 的 `double`、Java 的 `double` 完全一致。

本模块内容和 [[f32|std::f32]] 一一对应，只是常量值不同：`MAX`、`MIN`、`MIN_POSITIVE`、`EPSILON`、`NAN`、`INFINITY` 以及 `RADIX`、`MANTISSA_DIGITS`、`DIGITS`、`MIN_EXP` 等。它们描述「这个类型能表示什么」，同一个名字从 Rust 1.43 起也是 [[primitive.浮点类型|Type f64]] 的关联常量（`f64::MAX`），模块级路径已标记为 `deprecated`。

数学常量则在子模块 `std::f64::consts` 里：`PI`、`E`、`SQRT_2`、`LN_2`、`FRAC_PI_2`、`TAU` 等，没有关联常量替代，必须从这个子模块取。

## 快速上手

```rust
fn main() {
    // 表示方式与精度
    assert_eq!(f64::RADIX, 2);
    assert_eq!(f64::MANTISSA_DIGITS, 53);
    assert_eq!(f64::DIGITS, 15); // 十进制约 15~17 位有效数字

    println!("MAX          = {:e}", f64::MAX);          // 1.7976931348623157e308
    println!("MIN_POSITIVE = {:e}", f64::MIN_POSITIVE); // 2.2250738585072014e-308
    println!("EPSILON      = {:e}", f64::EPSILON);      // 2.220446049250313e-16
    println!("2 的指数范围  = {}..={}", f64::MIN_EXP, f64::MAX_EXP);
    println!("10 的指数范围 = {}..={}", f64::MIN_10_EXP, f64::MAX_10_EXP);

    // 0.1 + 0.2 != 0.3，比较时要给容差
    let sum: f64 = 0.1 + 0.2;
    assert!(sum != 0.3);
    assert!((sum - 0.3).abs() < f64::EPSILON);
    println!("0.1 + 0.2 = {:?}", sum);

    // 无穷、负无穷与 NaN
    assert_eq!(1.0f64 / 0.0, f64::INFINITY);
    assert_eq!(-1.0f64 / 0.0, f64::NEG_INFINITY);
    assert!((f64::INFINITY - f64::INFINITY).is_nan());
    assert!(f64::INFINITY > f64::MAX);

    // 1.0 与它的下一个可表示值只差 EPSILON
    assert_eq!(1.0f64 + f64::EPSILON, 1.000_000_000_000_000_2);

    // 子模块 consts 提供数学常量
    let circumference = 2.0 * std::f64::consts::PI * 1.0;
    assert!((circumference - 6.283_185_307_179_586).abs() < 1e-12);
    assert!((std::f64::consts::E - 2.718_281_828_459_045).abs() < 1e-15);

    // 不用写后缀时，浮点字面量默认就是 f64
    let x = 1.5;
    assert_eq!(x * 2.0, 3.0);
}
```

## 常用条目

| 条目 | 说明 |
| --- | --- |
| `std::f64::MAX` | 最大有限值，约 `1.80e308`；推荐写 `f64::MAX`。 |
| `std::f64::MIN` | 最小有限值（负数），约 `-1.80e308`。 |
| `std::f64::MIN_POSITIVE` | 最小正**规格化**值，约 `2.23e-308`。 |
| `std::f64::EPSILON` | 机器精度 ε，约 `2.22e-16`，浮点比较的常用容差。 |
| `std::f64::INFINITY` | 正无穷，`1.0 / 0.0` 得到它。 |
| `std::f64::NEG_INFINITY` | 负无穷。 |
| `std::f64::NAN` | 非数字，与任何值比较都为 `false`。 |
| `std::f64::RADIX` | 内部表示的基数，恒为 `2`。 |
| `std::f64::MANTISSA_DIGITS` | 二进制有效位数，`53`。 |
| `std::f64::DIGITS` | 十进制有效位数，`15`。 |
| `std::f64::MIN_EXP` / `MAX_EXP` | 二进制指数下界加一 `-1021` / 上界 `1024`。 |
| `std::f64::MIN_10_EXP` / `MAX_10_EXP` | 十进制指数下界 `-307` / 上界 `308`。 |
| `std::f64::consts::PI` | 圆周率，双精度近似值。 |
| `std::f64::consts::E` | 自然常数 e，双精度近似值。 |
| `std::f64::consts` | 数学常量子模块：`PI`、`E`、`SQRT_2`、`TAU` 等。 |

## 注意事项

> [!tip] 默认选 `f64`
> 除非内存或带宽敏感（图形、向量运算、海量数值），否则用 `f64`：它的精度余量大，多数累积误差不会立刻暴露。`f32` 只在确定可以承受精度损失时使用。

> [!danger] 不要用浮点做金额计算
> `0.1`、`0.2` 这类十进制小数在二进制浮点里没有精确表示，`0.1 + 0.2 != 0.3`。金额请用整数最小单位（如「分」用 `i64`），或专门的定点/十进制库，不要用 `f64` 累加账目。

> [!warning] `f64` 既不 `Eq` 也不 `Ord`
> 因为 `NaN` 不满足全序，`f64` 只实现 `PartialEq`/`PartialOrd`，不能当 [[collections.BTreeMap|BTreeMap]] 的键。需要排序时用 `f64::total_cmp`（1.62 起）或先过滤掉 `NaN`，需要当键时用 `ordered-float` 之类的包装。
