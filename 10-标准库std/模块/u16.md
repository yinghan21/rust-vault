# std::u16

> [!abstract] 一句话
> `std::u16` 是 16 位无符号整数的「常量模块」：只有 `MIN`、`MAX` 两个常量，官方已建议改用原始类型上的关联常量。

## 模块简介

`std::u16` 是个**冗余模块**：它不定义类型，只把 `u16` 的取值边界挂成模块路径 `std::u16::MIN` / `std::u16::MAX`。这两个常量已被标注「未来版本弃用」，现在写只报 `deprecated` 警告，将来会变成硬错误；官方推荐直接写原始类型上的 `u16::MIN` / `u16::MAX`。

**整数的方法不在这个模块里。** 溢出检查、进制解析、位运算、字节序转换全部定义在原始类型 `u16` 上，属于[[primitive.整数类型|整数类型]]页面的内容 —— 例如 `u16::checked_add`、`u16::wrapping_sub`、`u16::from_str_radix`、`u16::to_be_bytes`。位宽 `BITS` 同样只在原始类型上有，模块里没有。所以本页只讲那两个常量，其余请移步该页。

`u16` 占 2 字节，范围 `0..=65535`。它有两个典型身份：一是 UTF-16 的**码元** —— Windows 的宽字符 API、Java 和 JavaScript 的字符串都是 UTF-16，一个 `char` 会编码成 1–2 个 `u16`；二是协议字段与端口号这种固定 16 位的值。宽度小意味着容易溢出，累加前先转成 `u32` / `u64` 更省心。

## 快速上手

```rust
fn main() {
    #[allow(deprecated)]
    let legacy_max = std::u16::MAX;
    assert_eq!(legacy_max, 65_535);

    assert_eq!(u16::MIN, 0);
    assert_eq!(u16::MAX, 65_535);
    assert_eq!(u16::BITS, 16);
    assert_eq!(std::mem::size_of::<u16>(), 2);

    // UTF-16 码元：一个字符编码成 1–2 个 u16
    let units: Vec<u16> = "中".encode_utf16().collect();
    assert_eq!(units, vec![0x4E2D]);
    assert_eq!(char::from_u32(units[0] as u32), Some('中'));

    // 端口号、协议字段常用 u16 承载
    let port: u16 = 8080;
    assert_eq!(port.to_be_bytes(), [0x1F, 0x90]);
    assert_eq!(u16::from_be_bytes([0x1F, 0x90]), port);

    // 收窄要检查：超出范围返回 Err，而不是静默截断
    assert!(u16::try_from(70_000u32).is_err());
    assert_eq!(u32::from(port), 8080u32);

    println!("u16 范围 = {} ..= {}", u16::MIN, u16::MAX);
}
```

## 常用条目

| 条目 | 说明 |
| --- | --- |
| `std::u16::MIN` | 最小值 `0`，模块路径已标记为待弃用。 |
| `std::u16::MAX` | 最大值 `65535`，模块路径已标记为待弃用。 |
| `u16::MIN` / `u16::MAX` | 推荐写法：原始类型上的取值边界。 |
| `u16::BITS` | 位宽，恒为 `16u32`；模块里没有这个常量。 |
| `u16::to_be` / `to_le` / `swap_bytes` | 显式换字节序，网络协议必备。 |
| `u16::to_be_bytes` / `from_be_bytes` | 与两字节大端数组互转。 |
| `u16::from_str_radix` | 按 2–36 进制解析字符串为 `u16`。 |
| `u16::checked_add` / `checked_mul` | 溢出时返回 `None`。 |
| `u16::wrapping_sub` / `saturating_sub` | 下溢回绕 / 钳制到 `0`。 |
| `u16::abs_diff` | 两数之差的绝对值，无符号也安全。 |
| `u16::count_ones` / `leading_zeros` | 位计数与前导零个数。 |
| `u16::div_ceil` | 向上取整除法，算块数 / 页数常用。 |
| `u16::try_from` | 由更宽整数收窄，越界返回 `Err`。 |
| `str::encode_utf16` | 把字符串展开成 UTF-16 码元迭代器。 |

## 注意事项

> [!warning] 模块常量行将弃用
> `std::u16::MIN` / `std::u16::MAX` 编译能过但会报 `deprecated` 警告，官方计划在未来版本移除。新代码写 `u16::MIN` / `u16::MAX`，本来也没有 `BITS` 可以在这里用。

> [!danger] UTF-16 不是 UTF-8
> Rust 的 `String` / `&str` 一律是 UTF-8，只有和 Windows API、Java/JS 互操作时才需要 `Vec<u16>`。转换用 `str::encode_utf16` 和 `String::from_utf16`；自己按字节切分会把代理对（surrogate pair）切坏，产生无法还原的乱码。

> [!tip] 字节序别猜
> 网络字节序是大端：`port.to_be_bytes()` 直接给出 wire 上的两字节。用 `as` 拆高低字节（`(x >> 8) as u8` 之类）在大小端机器上表现一样但极易写错顺序，需要端序转换时优先 `to_be` / `to_le` / `from_be_bytes`。
