# std::i8

> [!abstract] 一句话
> `std::i8` 是 8 位有符号整数类型的「常量模块」：只有 `MIN`、`MAX` 两个常量，且已被标记为弃用。

## 模块简介

`std::i8` 本身是个**冗余模块**：它不定义类型，只是把 `i8` 的取值边界 `MIN`（-128）和 `MAX`（127）挂成一个模块路径，方便早年写成 `std::i8::MAX`。这些模块常量现在都是 `deprecated` 状态，官方建议一律改用原始类型上的关联常量 `i8::MIN` / `i8::MAX` / `i8::BITS`，二者值相同，新代码不应再引入 `std::i8` 路径。

**整数类型的方法不在这个模块里。** 加减乘除、溢出检查、字符串解析、字节序转换这些能力全部定义在原始类型 `i8` 上，属于[[primitive.整数类型|整数类型]]页面的内容，例如 `i8::checked_add`、`i8::wrapping_mul`、`i8::from_str_radix`、`i8::to_be_bytes`。所以本页只讲模块里那两个常量，其余请移步该页。

`i8` 占 1 字节，取值范围 `-128..=127`。它适合紧凑的字节级数据（例如协议字段、量化后的采样值、需要和 `u8` 互转的有符号差值）。因为范围太窄，累加、计数、索引这类场景请用 `i32` 或 `isize`，否则很容易溢出。

## 快速上手

```rust
fn main() {
    // 模块常量：仍可用，但已是 deprecated，只在旧代码里能见到
    #[allow(deprecated)]
    let old_max = std::i8::MAX;
    assert_eq!(old_max, 127);

    // 新代码统一用原始类型上的关联常量
    assert_eq!(i8::MIN, -128);
    assert_eq!(i8::MAX, 127);
    assert_eq!(i8::BITS, 8);
    assert_eq!(i8::BITS as usize, std::mem::size_of::<i8>() * 8);

    // 边界运算：checked_* 溢出返回 None，wrapping_* 直接回绕
    assert_eq!(i8::MAX.checked_add(1), None);
    assert_eq!(i8::MIN.checked_sub(1), None);
    assert_eq!(i8::MAX.wrapping_add(1), i8::MIN);

    // 收窄转换超出范围会返回 Err，不会静默截断
    assert!(i8::try_from(200i32).is_err());

    println!("i8 范围 = {} ..= {}", i8::MIN, i8::MAX);
}
```

## 常用条目

| 条目 | 说明 |
| --- | --- |
| `std::i8::MIN` | 最小值 `-128`，模块路径已弃用。 |
| `std::i8::MAX` | 最大值 `127`，模块路径已弃用。 |
| `i8::MIN` / `i8::MAX` | 推荐写法：原始类型上的取值边界。 |
| `i8::BITS` | 位宽，恒为 `8u32`。 |
| `i8::from_str_radix` | 按 2–36 进制解析字符串为 `i8`。 |
| `"-42".parse::<i8>()` | 经由 `FromStr` 把字符串解析成整数。 |
| `i8::checked_add` / `checked_sub` | 溢出时返回 `None` 而不是 panic。 |
| `i8::wrapping_add` / `wrapping_mul` | 溢出时按二进制补码回绕。 |
| `i8::saturating_add` | 溢出时钳制到 `MIN` / `MAX`。 |
| `i8::try_from` | 由更宽整数安全收窄，越界返回 `Err`。 |
| `i8::to_be_bytes` / `from_be_bytes` | 与大端字节数组互转，适合协议解析。 |
| `i8::count_ones` / `leading_zeros` | 位计数与位串前导零个数。 |
| `i8::unsigned_abs` | 返回绝对值对应的 `u8`，对 `MIN` 也安全。 |

## 注意事项

> [!warning] 模块常量已弃用
> 写 `std::i8::MIN` 会触发 `deprecated` 警告，官方推荐直接写 `i8::MIN`。本页属于历史包袱，新代码不要用；`BITS` 更是只存在于原始类型上，模块里没有。

> [!danger] 溢出行为随编译模式变化
> debug 构建下 `127i8 + 1` 会 panic，release 构建下静默回绕成 `-128`——同一个表达式两种结果。处理外部输入时用 `checked_*` / `saturating_*` 把语义写死。另外 `i8::MIN.abs()` 在 debug 下直接 panic，因为 `-(-128)` 溢出；要取绝对值用返回 `u8` 的 `unsigned_abs()`。

> [!tip] 选型建议
> 只存单字节且需要负值（差值、温度偏移、ADC 偏移量）时用 `i8`；要读写原始字节数组用 `u8` 再按需转换。默认整数类型仍是 `i32`，索引和长度用 `isize` / `usize`。
