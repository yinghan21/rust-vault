# std::i128

> [!abstract] 一句话
> `std::i128` 是 128 位有符号整数类型的「常量模块」：只有 `MIN`、`MAX` 两个已弃用的常量。

## 模块简介

`std::i128` 是个**冗余模块**，只把 `i128` 的边界以模块路径再导出一遍：`MIN` 是 -170141183460469231731687303715884105728，`MAX` 是 170141183460469231731687303715884105727。这两个常量已标记 `deprecated`，官方推荐写原始类型上的关联常量 `i128::MIN` / `i128::MAX` / `i128::BITS`。

**整数类型的方法不在本模块里。** `checked_add`、`from_str_radix`、`to_be_bytes`、`pow` 等全部定义在原始类型 `i128` 上，见[[primitive.整数类型|整数类型]]页面。本页仅说明模块里的两个常量。

`i128` 占 16 字节，范围约 ±1.7×10³⁸，足以装下任意两个 `u64` 相乘的中间结果。它主要用于大数计算、UUID/哈希的十进制表示、金融高精度定点和编译器里的常量求值。注意它不是「更快的 i64」：在部分平台上 128 位运算由多条指令模拟，密集运算会明显变慢。

## 快速上手

```rust
fn main() {
    // 模块常量：已弃用的旧路径
    #[allow(deprecated)]
    let old_max = std::i128::MAX;
    assert_eq!(
        old_max,
        170_141_183_460_469_231_731_687_303_715_884_105_727
    );

    // 推荐写法：原始类型上的关联常量
    assert_eq!(i128::BITS, 128);

    // u64 装不下的大数，i128 装得下
    let squared: i128 = (u32::MAX as i128) * (u32::MAX as i128);
    assert!(squared > i64::MAX as i128);

    // 负值不能转成无符号，i128 也放不进 u64
    assert!(u128::try_from(-1i128).is_err());
    assert!(u64::try_from(i128::MAX).is_err());

    assert_eq!(i128::from(u64::MAX), 18_446_744_073_709_551_615);
    println!("i128 范围 = {} ..= {}", i128::MIN, i128::MAX);
}
```

## 注意事项

> [!warning] 模块常量已弃用
> `std::i128::MAX` 会触发 `deprecated` 警告，改用 `i128::MAX`。`BITS` 同样只在原始类型上有。

> [!danger] 字面量必须写得下
> `i128::MAX + 1` 这种常量表达式在编译期就会报 `arithmetic_overflow`，而不是运行时 panic。写大数字面量时用下划线分组可读性更好，例如 `170_141_183_460_469_231_731_687_303_715_884_105_727`；没有后缀且超出 `i32` 时，务必靠类型标注让编译器推断成 `i128`。

> [!tip] 只在真需要时用
> 普通业务用 `i64` 足够；只有明确要「两个 `u64` 相乘不溢出」或「十进制定点高精度」时才上 `i128`。若要做任意精度运算，`i128` 也不够，那是外部 crate 的领域。
