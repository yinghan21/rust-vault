# std::u8

> [!abstract] 一句话
> `std::u8` 是 8 位无符号整数的「常量模块」：只有 `MIN`、`MAX` 两个常量，官方已建议改用原始类型上的关联常量。

## 模块简介

`std::u8` 本身是个**冗余模块**：它不定义类型，只把 `u8` 的取值边界挂成模块路径，方便早年写成 `std::u8::MIN` / `std::u8::MAX`。这两个模块常量已被标注「未来版本弃用」，现在编译只会报 `deprecated` 警告，将来会变成硬错误。新代码一律写 `u8::MIN` / `u8::MAX`，值完全相同。

**整数的方法不在这个模块里。** 加减乘除、溢出检查、进制解析、位运算、字节序转换全部定义在原始类型 `u8` 上，属于[[primitive.整数类型|整数类型]]页面的内容 —— 例如 `u8::checked_add`、`u8::wrapping_mul`、`u8::from_str_radix`、`u8::to_be_bytes`。连位宽 `BITS` 也只有原始类型上才有，`std::u8` 模块里根本没有这个常量。所以本页只讲那两个常量，其余请移步该页。

`u8` 占 1 字节，范围 `0..=255`，是**字节**的默认类型：`Vec<u8>` / `[u8]` 承载文件内容、网络报文和二进制协议，字节字面量写 `b'A'`。它没有负数，所以「差值」这类可能为负的量要么用 `i8`（更宽时用有符号类型），要么用 `u8::abs_diff` 直接取无符号的绝对差。

## 快速上手

```rust
fn main() {
    // 模块常量仍然存在，但官方已标记「未来版本弃用」
    #[allow(deprecated)]
    let legacy_max = std::u8::MAX;
    assert_eq!(legacy_max, 255);

    // 推荐写法：原始类型上的关联常量
    assert_eq!(u8::MIN, 0);
    assert_eq!(u8::MAX, 255);
    assert_eq!(u8::BITS, 8);
    assert_eq!(u8::BITS as usize, std::mem::size_of::<u8>() * 8);

    // 字节与 ASCII 字符互转
    let b = b'A';
    assert!(b.is_ascii_uppercase());
    assert_eq!(b.to_ascii_lowercase(), b'a');
    assert_eq!(char::from(b), 'A');

    // 溢出检查与进制解析
    assert_eq!(u8::MAX.checked_add(1), None);
    assert_eq!(u8::MAX.wrapping_add(1), u8::MIN);
    assert_eq!(u8::from_str_radix("ff", 16), Ok(255));
    assert_eq!("42".parse::<u8>(), Ok(42));

    println!("u8 范围 = {} ..= {}", u8::MIN, u8::MAX);
}
```

## 常用条目

| 条目 | 说明 |
| --- | --- |
| `std::u8::MIN` | 最小值 `0`，模块路径已标记为待弃用。 |
| `std::u8::MAX` | 最大值 `255`，模块路径已标记为待弃用。 |
| `u8::MIN` / `u8::MAX` | 推荐写法：原始类型上的取值边界。 |
| `u8::BITS` | 位宽，恒为 `8u32`；模块里没有这个常量。 |
| `u8::from_str_radix` | 按 2–36 进制解析字符串为 `u8`。 |
| `"42".parse::<u8>()` | 经由 `FromStr` 解析十进制字符串。 |
| `u8::checked_add` / `checked_sub` | 溢出时返回 `None` 而不是 panic。 |
| `u8::wrapping_add` / `wrapping_mul` | 溢出时按 2⁸ 回绕。 |
| `u8::saturating_add` | 溢出时钳制在 `0` / `255`。 |
| `u8::abs_diff` | 两数之差的绝对值，结果仍是 `u8`。 |
| `u8::to_be_bytes` / `from_be_bytes` | 与单字节数组互转，写二进制协议常用。 |
| `u8::count_ones` / `leading_zeros` | 置位个数与前导零个数。 |
| `u8::is_ascii_alphabetic` / `to_ascii_uppercase` | ASCII 判断与大小写转换。 |
| `char::from(u8)` | 把字节按其码点（`0..=255`）转成 `char`。 |

## 注意事项

> [!warning] 模块常量行将弃用
> `std::u8::MIN` / `std::u8::MAX` 目前还能编过，但会触发 `deprecated` 警告，官方说明是「未来版本弃用」，届时删除。示例里的 `#[allow(deprecated)]` 只为展示历史路径，别照着写。同时别指望模块里有 `BITS`、`from_str_radix` —— 那些只在原始类型上。

> [!danger] 溢出与截断
> debug 构建下 `255u8 + 1` 会 panic，release 构建下静默回绕成 `0`；而 `as` 转换（如 `300i32 as u8`）在**任何**构建下都静默截断成 `44`。处理外部输入用 `checked_*` / `saturating_*`，跨宽度用 `try_from`。

> [!tip] 字节不是字符
> `String` 内部是 UTF-8，一个汉字占 3 个 `u8`，按字节遍历会看到半个字符的编码。要按字符处理用 `s.chars()`；只有确实需要原始字节（编解码、协议、I/O）时才把数据当 `u8` 处理。
