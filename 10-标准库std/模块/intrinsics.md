# std::intrinsics

> [!warning] 实验性模块
> 该模块需要 nightly 工具链，并通过 `#![feature(...)]` 启用，API 可能随时变化，**不要用于生产代码**。

## 模块简介

`std::intrinsics` 是编译器内建函数（compiler intrinsics）的入口。这些函数属于 `core` 的实现细节，官方明确表示不应在标准库之外使用——需要某项能力时，应当调用标准库给出的稳定封装，例如 `ptr::copy`、`<*const T>::offset`、`mem::size_of`。模块里的函数只是声明，真正的实现位于编译器：一部分在 MIR 阶段被降级，其余分别由 LLVM 后端和常量求值器实现。

## 主要条目（共 237 项，下列为代表项，完整列表见官方文档）
- `size_of` / `size_of_val`：类型的字节大小 / 被引用值的大小。
- `align_of` / `align_of_val`：类型的最小对齐 / 被引用值的对齐要求。
- `transmute`：把一个值的位重新解释成另一种类型。
- `copy_nonoverlapping`：`ptr::copy_nonoverlapping` 的别名，改用后者。
- `assume`：告知优化器条件恒为真，条件不成立即未定义行为。
- `ctlz` / `cttz` / `ctpop`：前导零、尾随零与置位比特的计数。
- `volatile_load` / `volatile_store`：易失读写，编译器不得将其优化掉。
- `prefetch_read_data`：提示插入数据预取指令，不支持时为空操作。
- `type_name` / `abort`：取出类型的静态名称 / 终止当前进程。
