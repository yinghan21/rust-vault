# std::u32

> [!abstract] 一句话
> `std::u32` 是 32 位无符号整数的「常量模块」：只有 `MIN`、`MAX` 两个常量，官方已建议改用原始类型上的关联常量。

## 模块简介

`std::u32` 是个**冗余模块**：它不定义类型，只把 `u32` 的取值边界挂成模块路径 `std::u32::MIN` / `std::u32::MAX`，方便早年代码引用。这两个常量已被标注「未来版本弃用」，现在用只会得到 `deprecated` 警告，将来会变成硬错误；新代码直接写 `u32::MIN` / `u32::MAX`。

**整数的方法不在这个模块里。** 溢出检查、进制解析、位运算、字节序转换全部定义在原始类型 `u32` 上，属于[[primitive.整数类型|整数类型]]页面的内容 —— 例如 `u32::checked_mul`、`u32::wrapping_mul`、`u32::from_str_radix`、`u32::to_be_bytes`。位宽 `BITS` 也只在原始类型上有。所以本页只讲那两个常量，其余请移步该页。

`u32` 占 4 字节，范围 `0..=4294967295`，有两个特殊身份：一是 **Unicode 标量值**的取值范围 —— `char` 本质上就是一个「合法的 `u32`」，`u32::from('中')` 与 `char::from_u32` 是这两个世界之间的桥；二是最常用的计数器、位标志与协议字段容器。注意 Rust 的默认整数类型是 `i32` 而不是 `u32`，需要非负时要显式标注。

## 快速上手

```rust
fn main() {
    #[allow(deprecated)]
    let legacy_max = std::u32::MAX;
    assert_eq!(legacy_max, 4_294_967_295);

    assert_eq!(u32::MIN, 0);
    assert_eq!(u32::MAX, 4_294_967_295);
    assert_eq!(u32::BITS, 32);

    // Unicode 码位就在 u32 的范围里，但只有一部分是合法字符
    assert_eq!(char::from_u32(0x4E2D), Some('中'));
    assert_eq!(char::from_u32(0xD800), None); // 代理区不是合法标量值
    assert_eq!(u32::from('中'), 0x4E2D);

    // 位标志：一个 u32 放 32 个开关
    let mut flags: u32 = 0;
    flags |= 1 << 3;
    assert_eq!(flags.count_ones(), 1);
    assert!(flags & (1 << 3) != 0);

    // 大数运算要留意溢出
    assert_eq!(u32::MAX.checked_mul(2), None);
    assert_eq!(u64::from(u32::MAX) * 2, 8_589_934_590);

    println!("u32 范围 = {} ..= {}", u32::MIN, u32::MAX);
}
```

## 常用条目

| 条目 | 说明 |
| --- | --- |
| `std::u32::MIN` | 最小值 `0`，模块路径已标记为待弃用。 |
| `std::u32::MAX` | 最大值 `4294967295`，模块路径已标记为待弃用。 |
| `u32::MIN` / `u32::MAX` | 推荐写法：原始类型上的取值边界。 |
| `u32::BITS` | 位宽，恒为 `32u32`；模块里没有这个常量。 |
| `u32::from(char)` | 取字符的 Unicode 码位。 |
| `char::from_u32` | 由码位构造字符，非法码位返回 `None`。 |
| `u32::to_be_bytes` / `from_be_bytes` | 与四字节大端数组互转。 |
| `u32::from_str_radix` | 按 2–36 进制解析，例如解析 `"ff"`。 |
| `u32::checked_mul` / `checked_add` | 溢出时返回 `None`。 |
| `u32::wrapping_mul` / `saturating_mul` | 回绕 / 钳制到 `MAX`，混洗哈希时常用。 |
| `u32::swap_bytes` | 反转四个字节的顺序。 |
| `u32::count_ones` / `leading_zeros` | 位标志常用的位计数。 |
| `u32::is_power_of_two` | 是否为 2 的幂，配合 `next_power_of_two`。 |
| `u32::try_from` | 由 `u64` 等更宽类型收窄，越界返回 `Err`。 |

## 注意事项

> [!warning] 模块常量行将弃用
> `std::u32::MIN` / `std::u32::MAX` 会触发 `deprecated` 警告，官方计划在未来版本移除。新代码写 `u32::MIN` / `u32::MAX`；模块里也从来没有 `BITS`、`from_str_radix` 这些位置。

> [!danger] 溢出与截断
> debug 下 `u32::MAX + 1` panic，release 下回绕成 `0`；`as` 转换则是**任何构建**都静默截断（`300u32 as u8 == 44`）。累加计数用 `checked_add`，收窄用 `try_from`。位标志的 `flags & mask != 0` 判断没问题，但掩码请写成常量或 `const`，别在两处手写同一个字面量。

> [!tip] 别拿 u32 当长度
> 切片下标和 `Vec::len()` 都是 `usize`，把长度存进 `u32` 在 64 位平台上要 `try_from`，省下的 4 字节通常不值得。反过来，需要「在所有平台都是 4 字节」的协议字段、CRC、像素值时才该用 `u32` —— 因为 `usize` 的宽度是平台相关的。
