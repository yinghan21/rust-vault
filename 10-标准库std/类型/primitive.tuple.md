# `(T, U, ..)`

> [!abstract] 一句话
> 元组是**长度固定、元素类型可以不同**的聚合值：`("hello", 5, 'c')` 的类型是 `(&str, i32, char)`；元数（元素个数）是类型的一部分。

## 简介

元组有三个关键性质：

- **有限**：长度固定，也叫 arity（元数）；写进类型里，`(i32, i32)` 与 `(i32, i32, i32)` 是完全不同的类型，不能互相赋值。
- **异构**：每个位置可以是不同类型，这正是它区别于 [[primitive.array|Type array]]（要求元素同类型）的地方。
- **按下标访问、不按名字**：用 `.0`、`.1` 取值，没有字段名，也没有按运行时下标取值的办法。

长度 0 的元组 `()` 叫**单元类型**，只有一个值 `()`，大小为零，是「没有有意义返回值」的函数返回类型；长度 1 的元组必须写成 `(T,)`，那个逗号不能省。

元组最常见的用途是「一次返回多个值」和「临时打包几个值」，例如 `HashMap::iter()` 产出 `(&K, &V)`、`split_at` 返回 `(&[T], &[T])`。当字段个数变多、需要名字或需要方法时，应改用结构体——元组没法给字段写文档、也不方便演进。与相邻类型对比：`[T; N]` 同类型且可索引遍历，结构体有命名字段，元组则处在「轻量打包」这个生态位上。

## 常用方法

数据源中元组的稳定方法为 **0 个**：`(T, U, ..)` 没有任何固有方法，它的能力全部来自语言语法与 trait 实现。

- **字段访问**：`t.0`、`t.1`……下标必须是字面量，不能用变量代替。
- **解构**：`let (a, b) = t;` 直接取出各元素；`let (a, b) = &t;` 借用解构，元素类型变为引用。
- **模式匹配**：在 `match`、`if let`、函数参数中都可以用元组模式。
- **赋值与交换**：`(x, y) = (y, x);`（`x`、`y` 已声明）可以原地交换。
- **trait**：元素类型都满足时，元组实现 `Debug`、`Clone`、`Copy`、`PartialEq`、`Eq`、`PartialOrd`、`Ord`、`Hash`、`Default` 等；标准库只为**有限元数**（最多 12 个）的元组生成这些实现。

## 示例

```rust
fn div_rem(a: i32, b: i32) -> (i32, i32) {
    (a / b, a % b) // 商和余数一次带回
}

fn main() {
    let t: (&str, i32, char) = ("hello", 5, 'c');
    assert_eq!(t.0, "hello"); // 按下标访问
    assert_eq!(t.1, 5);

    let (s, n, c) = t; // 解构
    assert_eq!(format!("{s}-{n}-{c}"), "hello-5-c");

    let (q, r) = div_rem(7, 2);
    assert_eq!((q, r), (3, 1)); // 元组可直接整体比较

    // () 是 0 元素元组，零大小
    assert_eq!(std::mem::size_of::<()>(), 0);
}
```

单元素元组、借用解构与交换：

```rust
fn main() {
    // 单元素元组必须带尾随逗号，否则只是一个带括号的值
    let single: (i32,) = (42,);
    assert_eq!(single.0, 42);

    let pair = (String::from("key"), 1);
    // 借用解构：不移动 pair 里的 String
    let (name, num) = &pair;
    assert_eq!(name.len(), 3);
    assert_eq!(*num, 1);
    assert_eq!(pair.1, 1);

    // 元组赋值可以原地交换
    let (mut x, mut y) = (1, 2);
    (x, y) = (y, x);
    assert_eq!((x, y), (2, 1));
}
```

## 常见陷阱

1. **`(42)` 不是元组**：单元素元组要写 `(42,)`，类型也要写 `(i32,)`；漏掉逗号会得到一个普通表达式，类型完全不同。
2. **不能用变量下标访问**：`t.i` 编译不过，元组只能写字面量下标或整体解构；需要动态索引说明该用数组或 `Vec`。
3. **解构会移动元素**：`let (a, b) = t;` 会移动非 `Copy` 元素，之后 `t` 不可再用；只想借用时写 `let (a, b) = &t;`。
4. **元素太多时换结构体**：元组元素多了以后字段含义全靠记忆，且只有有限元数的元组才有常见 trait 实现，字段超过三四个就应改结构体。
5. **别用元组当「匿名结构体」出现在公开 API**：参数和返回值里的元组无法加文档注释，版本演进时增删字段会破坏调用方。
