# 标准库总览

> [!abstract] 一句话
> `std` 是 Rust 的「标准库大礼包」：建立在 `core`（无堆、无 OS）与 `alloc`（堆分配）之上，提供文件、网络、线程、时间、集合等平台相关能力。

## std 是什么

Rust 的库分三层：

| 层 | crate | 能做什么 | 依赖 |
| --- | --- | --- | --- |
| 核心 | `core` | 基本类型、`Option`/`Result`、迭代器、`fmt`、原子操作 | 无（可 `no_std`） |
| 分配 | `alloc` | `Vec`、`String`、`Box`、`Rc`、`Arc` | 需要全局分配器 |
| 标准 | `std` | 上一层的全部 + 文件/网络/线程/时间/环境 | 需要操作系统 |

所以你在 `std::vec::Vec` 里看到的大部分方法，其实定义在 `alloc`；`std` 只是把它们重新导出，并补上平台相关模块。写嵌入式或内核时，通常只用 `core` + `alloc`。

## 稳定性约定

- **stable**：可以在稳定版编译器上使用，文档标注「Stable since 1.x.y」。
- **nightly / experimental**：需要 nightly 工具链和 `#![feature(...)]`，随时可能改动，**不要写进生产代码**。本库的模块页与条目页只收录稳定 API。
- **deprecated**：已弃用，文档会给出替代方案；本库的方法表不收录，必要时在「陷阱」里提一句。
- **版本**：本库依据 **Rust 1.99.1** 的 rustdoc 提取，方法签名与稳定版本号以该版本为准。你本地版本较旧时，个别新方法可能不存在。

## 怎么读官方文档

每个 rustdoc 页面结构相似：

1. 顶部：条目名、稳定版本、源码链接。
2. **简介**：是什么、典型用法。
3. **Examples**：可直接运行的代码。
4. **Implementations**：固有方法（本库方法表的来源）。
5. **Trait Implementations**：实现了哪些 trait（决定能不能 `clone`、`==`、`for` 循环）。
6. **Panics / Errors / Safety**：什么情况下 panic、返回什么错误、`unsafe` 的前置条件。

## 本库的 std 部分怎么组织

| 目录 | 内容 |
| --- | --- |
| `模块/` | 每个模块一页：简介、快速上手、常用条目，文末自动附全部条目表 |
| `类型/` | 核心类型与原始类型：`Option`、`Result`、`Vec`、`String`、`str`、`Duration`… |
| `集合/` | `HashMap`、`BTreeMap`、`VecDeque`、`BinaryHeap` 等 |
| `IO与网络/` | `File`、`BufReader`、`TcpStream`、`CString`、`Command` |
| `并发/` | `Mutex`、`RwLock`、`Arc` 等并发原语 |
| `特质/` | `Iterator`、`Clone`、`Display`、`Read`、`Error` 等 |
| `函数与宏/` | `println!`、`vec!`、`format!`、`mem::swap` 等 |

## 学习建议

1. 先掌握 [[option.Option|Option]]、[[result.Result|Result]]、[[vec.Vec|Vec]]、[[string.String|String]]、[[iter.Iterator|Iterator]] 五个条目——它们覆盖了日常代码的 80%。
2. 遇到「这个类型能做什么」的问题，先看条目的**方法表**，再看「相关」里的 trait 页。
3. 想确认某方法从哪个版本开始有，看方法表上方的稳定版本标注或官方文档的 `1.x.y` 徽章。
4. 不要背 API；记住模块划分和查询方式即可。
