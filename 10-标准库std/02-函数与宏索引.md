# 函数与宏索引

> [!tip] 说明
> `std` 根下的常用宏与自由函数。宏名带 `!`，第一个参数通常是格式化字符串。

| 名称 | 类型 | 一句话 |
| --- | --- | --- |
| [[10-标准库std/函数与宏/macro.assert|`assert!`]] | 宏 | 断言布尔表达式为真，为假就调用 panic!；release 下依然检查、无法关闭，展开成 if !cond { panic!(..) }。 |
| [[10-标准库std/函数与宏/macro.dbg|`dbg!`]] | 宏 | 把表达式以 Debug 形式连文件名、行号一起打到 stderr，然后把表达式原值返回，取其值不打断写代码。 |
| [[10-标准库std/函数与宏/macro.format|`format!`]] | 宏 | 用格式串把运行时表达式插值成一个新的 String 并返回，展开成 fmt::format(format_args!(..))。 |
| [[10-标准库std/函数与宏/macro.matches|`matches!`]] | 宏 | 判断表达式是否匹配某个模式，返回 bool；展开成只有 true/false 两个分支的 match，可带 if 守卫。 |
| [[10-标准库std/函数与宏/macro.panic|`panic!`]] | 宏 | 立刻让当前线程 panic，带上自定义消息并沿栈展开；返回类型是 !，可以放进任何需要表达式的位置。 |
| [[10-标准库std/函数与宏/macro.println|`println!`]] | 宏 | 把格式化后的文本写到标准输出并补一个换行，展开成「format_args! + 写 stdout」的语句，返回 ()。 |
| [[10-标准库std/函数与宏/macro.todo|`todo!`]] | 宏 | 标记尚未实现的代码：一旦执行就 panic，消息为「not yet implemented」，类型是 ! 所以能顶替任何返回值。 |
| [[10-标准库std/函数与宏/macro.vec|`vec!`]] | 宏 | 用类似数组字面量的语法构造 Vec，两种形式分别对应逐个列举与「值 + 个数」，返回 Vec<T>。 |
| [[10-标准库std/函数与宏/macro.write|`write!`]] | 宏 | 把格式化后的数据写进任意有 write_fmt 的 writer，返回该方法的返回值（fmt::Result 或 io::Result）。 |
| [[10-标准库std/函数与宏/env.args|`args`]] | 函数 | 返回程序启动时的命令行参数迭代器，第一项通常是可执行文件路径。 |
| [[10-标准库std/函数与宏/io.copy|`copy`]] | 函数 | 把 reader 的全部内容流式搬到 writer，直到 reader 读到 EOF，返回复制的字节数。 |
| [[10-标准库std/函数与宏/mem.drop|`drop`]] | 函数 | 把值按值接管并立刻丢弃，用来提前结束作用域；对 Copy 类型毫无作用，本质是空函数体加一次参数移除。 |
| [[10-标准库std/函数与宏/process.exit|`exit`]] | 函数 | 立即以指定退出码终止当前进程，立刻返回 OS，但不会运行任何析构函数。 |
| [[10-标准库std/函数与宏/cmp.max|`max`]] | 函数 | 按 Ord 比较并返回两个值中较大的那个；两者相等时返回第二个参数，与 min 的取舍方向相反。 |
| [[10-标准库std/函数与宏/cmp.min|`min`]] | 函数 | 按 Ord 比较并返回两个值中较小的那个；两者相等时返回第一个参数，按值传入、按值返回。 |
| [[10-标准库std/函数与宏/fs.read_to_string|`read_to_string`]] | 函数 | 一次性把一个文件的全部内容读成 String，文件不存在或内容不是合法 UTF-8 都返回 Err。 |
| [[10-标准库std/函数与宏/mem.replace|`replace`]] | 函数 | 把 src 放进 dest 指向的位置，返回原来的值；两个值都不会被析构，也不需要 Clone 或 Default。 |
| [[10-标准库std/函数与宏/thread.sleep|`sleep`]] | 函数 | 让当前线程至少睡眠指定时长，会阻塞本线程，绝不会少睡但可能多睡。 |
| [[10-标准库std/函数与宏/thread.spawn|`spawn`]] | 函数 | 新建一个线程执行闭包，返回可 join 的 JoinHandle；闭包必须 move 且为 'static。 |
| [[10-标准库std/函数与宏/mem.swap|`swap`]] | 函数 | 交换两个可变引用指向的值，双方都不会被提前析构；不分配、不拷贝元素、不会 panic。 |
| [[10-标准库std/函数与宏/mem.take|`take`]] | 函数 | 把 dest 换成 T::default()，返回被换下来的旧值；等价于 replace(dest, T::default())，要求 T: Default。 |
| [[10-标准库std/函数与宏/env.var|`var`]] | 函数 | 按名字读取一个环境变量，返回 Result<String, VarError>，区分「不存在」与「不是 Unicode」。 |
| [[10-标准库std/函数与宏/fs.write|`write`]] | 函数 | 把一段字节整体写成文件内容：文件不存在就创建，已存在就整个覆盖；成功返回 io::Result<()>。 |
