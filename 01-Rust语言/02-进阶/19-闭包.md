# 闭包

> [!abstract] 一句话
> 闭包 = 匿名函数 + 捕获的环境。它按「只读、修改、拿走」三种方式捕获外部变量，对应的能力就是 `Fn`、`FnMut`、`FnOnce`。

## 为什么需要它

普通函数拿不到调用处的局部变量，于是 C 用函数指针加 `void*` 上下文、Java 的 lambda 只能读 `final` 变量、Python 的 lambda 延迟绑定且不限制修改，各有各的别扭。Rust 让闭包**推断**该借还是该移，并把「能调用几次、能不能改环境」编码进类型：编译器因此能阻止「闭包已被移空还被再调一次」这类错误，且泛型约束下调用可以完全内联。

## 捕获的三种方式

闭包用哪种方式捕获，取决于闭包体里怎么用外部变量——能借就借，必须移才移，**取最小权限**。

```rust
fn main() {
    let s = String::from("hello");
    let by_ref = || s.len(); // ① 不可变借用
    assert_eq!(by_ref(), 5);
    assert_eq!(s, "hello"); // s 仍可用

    let mut n = 0;
    let mut by_mut = || n += 1; // ② 可变借用
    by_mut();
    by_mut();
    drop(by_mut);
    assert_eq!(n, 2); // 借用结束后才能读

    drop(by_ref);
    let take = move || s; // ③ 按值移动，闭包交出 s
    assert_eq!(take(), "hello");
}
```

注意 `drop(by_mut)`：闭包存在期间它一直持有 `n` 的可变借用，此时读 `n` 会报 `E0502`；提前 `drop` 是闭合借用作用域的常用手法。

## `Fn`、`FnMut`、`FnOnce`

| 特质 | 调用时的 `self` | 能力 | 典型场景 |
| --- | --- | --- | --- |
| `Fn` | `&self` | 可反复调用，不改变环境 | 只读配置、格式化 |
| `FnMut` | `&mut self` | 可反复调用，可改环境 | 累加器、计数器 |
| `FnOnce` | `self` | 只能调用一次，可移出环境 | 交出所有权、清理逻辑 |

三者**逐级包含**：实现了 `Fn` 的闭包自动实现 `FnMut` 与 `FnOnce`，实现了 `FnMut` 的也实现 `FnOnce`。所以泛型约束写 `F: FnMut()` 能接受的范围比 `F: Fn()` 宽，写 `F: FnOnce()` 最宽。

## `move`：把所有权搬进闭包

`move` 强制按值捕获，是把闭包送进线程、或让闭包活过当前函数的必备手段（见 [[21-并发编程|并发编程]]）。

```rust
fn main() {
    let name = String::from("Rust");
    let greet = move || println!("你好，{}", name); // name 被移入闭包
    greet();
    // println!("{}", name); // ❌ E0382：name 已经不在外面了
}
```

`move` 只决定**捕获方式**，不决定实现哪个 `Fn` 特质：闭包体只读 `name`，它仍然只实现 `Fn`，可以反复调用。

## 作参数与返回值

作参数用泛型约束（静态分发、可内联）或 trait 对象（能存进 `Vec`、结构体字段）都行；返回闭包必须写 `impl Fn` 或 `Box<dyn Fn>`——闭包类型是编译器生成的匿名类型，无法手写，且不写 `move` 就会返回对局部变量的引用，报 `E0373`。

```rust
fn apply_twice<F: Fn(i32) -> i32>(f: F, x: i32) -> i32 { f(f(x)) }

fn adder(n: i32) -> impl Fn(i32) -> i32 { move |x| x + n }

fn counter() -> impl FnMut() -> i32 {
    let mut n = 0;
    move || { n += 1; n }
}

fn main() {
    let base = 10;
    assert_eq!(apply_twice(|x| x + base, 1), 21); // 泛型约束，单态化后零开销

    let add5 = adder(5);
    assert_eq!(add5(1), 6);

    let mut c = counter();
    assert_eq!(c(), 1);
    assert_eq!(c(), 2); // 状态保存在闭包自己身上

    // 要放进集合或结构体字段时用 Box<dyn Fn>
    let ops: Vec<Box<dyn Fn(i32) -> i32>> = vec![Box::new(|x| x + 1), Box::new(|x| x * 2)];
    assert_eq!(ops.iter().map(|f| f(3)).collect::<Vec<_>>(), vec![4, 6]);
}
```

## 与迭代器组合

[[18-迭代器|迭代器]] 的适配器参数全是闭包：`filter` 借用外部阈值、`map` 变换、`for_each` 原地累加、`sort_by_key` 提供排序键。

```rust
fn main() {
    let data = vec![1, 2, 3, 4, 5, 6];
    let threshold = 3;

    let squares: Vec<i32> = data.iter().copied().filter(|x| *x > threshold).map(|x| x * x).collect();
    assert_eq!(squares, vec![16, 25, 36]); // 闭包借用 threshold

    let mut sum = 0;
    data.iter().for_each(|x| sum += x); // FnMut 捕获 sum
    assert_eq!(sum, 21);

    let mut words = vec!["bbb", "a", "cc"];
    words.sort_by_key(|w| w.len());
    assert_eq!(words, vec!["a", "cc", "bbb"]);
}
```

## 常见错误与解决

| 错误 | 原因 | 解决 |
| --- | --- | --- |
| `E0596: cannot borrow as mutable` | 调 `FnMut` 闭包却没用 `mut` 绑定 | `let mut f = ...` |
| `E0373: closure may outlive the current function` | 闭包借用局部变量却被返回或送进线程 | 加 `move` |
| `E0505: cannot move out ... because it is borrowed` | 闭包还活着就移动它借用的值 | 先 `drop(闭包)` 或缩小作用域 |
| `E0507: cannot move out of ... in Fn closure` | `Fn` 闭包里想移出捕获值 | 改成 `FnOnce`，或用 `Option::take`/`clone` |
| `E0308: expected closure, found a different closure` | 每个闭包都是独立匿名类型 | 统一为 `&dyn Fn` 或 `Box<dyn Fn>` |
