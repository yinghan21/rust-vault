# 智能指针

> [!abstract] 一句话
> 智能指针是「像引用一样用、但额外管理资源」的结构体：它们实现 `Deref` 让你照常访问值，实现 `Drop` 在离开作用域时释放资源。

## 为什么需要它

`&T` 只能借用别人的数据，回答不了三个问题：**值放在堆上还是栈上**、**能不能有多个所有者**、**能不能绕过借用规则临时修改**。C++ 用 `unique_ptr`/`shared_ptr` 回答前两个但不管并发安全，Java 全靠 GC，Rust 则把每种策略做成一个独立类型，让编译器或运行时替你检查。

| 类型 | 所有权 | 可变性 | 跨线程 | 主要用途 |
| --- | --- | --- | --- | --- |
| `Box<T>` | 唯一 | 需要 `&mut` | 是（`T: Send`） | 堆分配、递归类型、trait 对象 |
| `Rc<T>` | 共享（计数） | 只有共享引用 | 否 | 单线程多所有者 |
| `Arc<T>` | 共享（原子计数） | 只有共享引用 | 是 | 跨线程共享（见 [[21-并发编程|并发编程]]） |
| `Cell<T>` | 唯一 | 整个值换进换出 | 是（`T: Send`） | `Copy` 小值、计数器 |
| `RefCell<T>` | 唯一 | 运行时借用检查 | 否 | 单线程内部可变性 |
| `Weak<T>` | 弱引用 | 不参与所有权 | 同 `Rc` | 打破循环引用 |

## `Box<T>`：把值放到堆上

`Box` 是最简单的一种：所有权唯一，离开作用域就释放。它最不可替代的用途是**递归类型**——不套一层指针，类型大小就是无限的。

```rust
#[derive(Debug)]
enum List {
    Cons(i32, Box<List>), // 没有 Box 会报 E0072: recursive type has infinite size
    Nil,
}

fn sum(list: &List) -> i32 {
    match list {
        List::Cons(v, next) => v + sum(next),
        List::Nil => 0,
    }
}

fn main() {
    let list = List::Cons(1, Box::new(List::Cons(2, Box::new(List::Nil))));
    assert_eq!(sum(&list), 3);
    println!("{:?}", list);
}
```

`Box<dyn Trait>` 也是 trait 对象的载体（见 [[16-trait 对象与动态分发|trait 对象]]），`Box<dyn Error>` 则是最常见的错误返回类型。

## `Rc<T>`：单线程多所有者

需要「多个地方共享同一份只读数据」时用 `Rc`，`clone` 只增加计数，不复制堆上数据。

```rust
use std::rc::Rc;

fn main() {
    let shared = Rc::new(vec![1, 2, 3]);
    let a = Rc::clone(&shared); // 计数 +1，数据不复制
    let b = Rc::clone(&shared);
    assert_eq!(Rc::strong_count(&shared), 3);

    drop(a);
    drop(b);
    assert_eq!(Rc::strong_count(&shared), 1); // 最后一个持有者释放时数据才被 drop
    assert_eq!(shared.len(), 3);
}
```

`Rc` 只能给出 `&T`：它不实现 `Send`，也无法可变借用。要改内部数据，就要引入下面的内部可变性。

## `Cell` 与 `RefCell`：内部可变性

编译器不允许通过 `&T` 修改值，但有时共享句柄必须能改（图、观察者、缓存）。`Cell` 和 `RefCell` 把借用检查从**编译期**挪到**运行期**。

```rust
use std::cell::{Cell, RefCell};

fn main() {
    // Cell：适合 Copy 小值，get 复制出来、set 整个换进去
    let hits = Cell::new(0);
    hits.set(hits.get() + 1);
    assert_eq!(hits.get(), 1);

    // RefCell：borrow / borrow_mut 在运行时检查，冲突会 panic
    let log = RefCell::new(Vec::new());
    log.borrow_mut().push("第一条");
    assert_eq!(log.borrow().len(), 1);
    assert!(log.try_borrow_mut().is_ok()); // try_ 版本返回 Result，不 panic
}
```

`RefCell` 的借用冲突是**运行时 panic**（`BorrowMutError`），编译器不再帮你兜底，所以借用范围要尽量短。

## `Rc<RefCell<T>>`：共享 + 可变

这个组合是单线程「共享可变状态」的标准解，代价是丢掉编译期检查、增加计数与借用检查开销。

```rust
use std::cell::RefCell;
use std::rc::Rc;

fn main() {
    let shared = Rc::new(RefCell::new(Vec::new()));
    let a = Rc::clone(&shared);
    let b = Rc::clone(&shared);

    a.borrow_mut().push(1); // 通过任意一个句柄修改同一份数据
    b.borrow_mut().push(2);
    assert_eq!(shared.borrow().len(), 2);
}
```

取舍建议：能用「唯一所有者 + `&mut`」表达时就别用它；确实需要共享可变时才用，并且把 `borrow_mut()` 的范围压到一两条语句。跨线程要换成 `Arc<Mutex<T>>` 或 `Arc<RwLock<T>>`。

## `Deref` 与 `Drop`：自定义智能指针

`Deref` 让 `MyBox<T>` 能像 `T` 一样调用方法（解引用强制转换），`Drop` 定义释放逻辑，两者合起来就是「智能」的来源。

```rust
use std::ops::Deref;

struct MyBox<T>(T);

impl<T> MyBox<T> {
    fn new(x: T) -> Self { MyBox(x) }
}

impl<T> Deref for MyBox<T> {
    type Target = T;
    fn deref(&self) -> &T { &self.0 }
}

struct Noisy(&'static str);

impl Drop for Noisy {
    fn drop(&mut self) {
        println!("释放 {}", self.0);
    }
}

fn main() {
    let x = MyBox::new(String::from("hi"));
    assert_eq!(&*x, "hi"); // 解引用强制转换：&MyBox<String> -> &str
    assert_eq!(x.len(), 2); // 方法调用自动解引用

    let _a = Noisy("a");
    let _b = Noisy("b"); // 逆序释放：先 b 后 a
}
```

## `Weak`：打破循环引用

两个 `Rc` 互相指向对方时计数永远不归零，内存泄漏。把其中一边改成 `Weak`（不增加强计数，`upgrade()` 返回 `Option<Rc<T>>`）就能打破环。

```rust
use std::cell::RefCell;
use std::rc::{Rc, Weak};

struct Node {
    name: &'static str,
    parent: RefCell<Weak<Node>>, // 父节点只弱引用
    children: RefCell<Vec<Rc<Node>>>,
}

fn main() {
    let leaf = Rc::new(Node { name: "leaf", parent: RefCell::new(Weak::new()), children: RefCell::new(vec![]) });
    let branch = Rc::new(Node { name: "branch", parent: RefCell::new(Weak::new()), children: RefCell::new(vec![Rc::clone(&leaf)]) });
    *leaf.parent.borrow_mut() = Rc::downgrade(&branch);

    let up = leaf.parent.borrow().upgrade().unwrap();
    assert_eq!(up.name, "branch");
    assert_eq!(Rc::strong_count(&branch), 1); // 叶子只弱引用父节点
    assert_eq!(Rc::weak_count(&branch), 1);
}
```

## 常见错误与解决

| 错误 | 原因 | 解决 |
| --- | --- | --- |
| `E0072: recursive type has infinite size` | 递归类型没有间接层 | 用 `Box`/`Rc` 包一层 |
| `E0277: Rc<...> cannot be sent between threads` | `Rc` 不实现 `Send` | 换成 `Arc` |
| `E0596: cannot borrow as mutable` | `Rc<T>` 只给共享引用 | 换 `Rc<RefCell<T>>` |
| `BorrowMutError` 运行时 panic | `RefCell` 同时存在读写借用 | 缩短借用范围，改用 `try_borrow_mut` |
| `E0509: cannot move out of type which implements Drop` | `Drop` 类型不能部分移出 | 用 `Option::take` 或 `std::mem::take` |
| 内存只增不减 | `Rc` 循环引用 | 用 `Weak` 打断环 |

## 练习

1. 用 `Box` 实现二叉树，并写一个递归求高度的函数。
2. 用 `Rc<RefCell<Vec<String>>>` 让两个「观察者」往同一个日志里追加内容，验证双方看到的长度一致。
3. 把第 2 题的 `Rc` 换成 `Arc`、`RefCell` 换成 `Mutex`，说明为什么必须一起换。
