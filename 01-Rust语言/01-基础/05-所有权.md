# 所有权

> [!abstract] 一句话
> Rust 不用 GC 也不用手动 `free`：每个值在任意时刻**只有一个所有者**，所有者离开作用域，值就被自动释放。

## 为什么需要它

在别的语言里，堆内存的管理方式通常是两种：

| 方式 | 代表语言 | 代价 |
| --- | --- | --- |
| 垃圾回收（GC） | Java、Go、C# | 运行时开销、不可预测的停顿 |
| 手动管理 | C、C++ | 忘记释放 = 内存泄漏；重复释放 / 悬垂指针 = 未定义行为 |
| 所有权 + 借用检查 | Rust | 编译期检查，运行时零开销 |

Rust 的选择是：把「谁负责释放」写进类型系统，由编译器在编译期验证，因此不需要 GC，也不需要你手动释放。

## 三条规则

1. Rust 中每个值都有一个**所有者**（owner）。
2. 同一时刻只能有**一个**所有者。
3. 所有者离开作用域时，值被自动**丢弃**（调用 `drop`）。

```rust
fn main() {
    {
        let s = String::from("hello"); // s 是这块堆内存的所有者
        println!("{}", s);
    } // 作用域结束，s 被 drop，堆内存自动释放
}
```

## 移动（move）：所有权会转移

把 `String` 赋值给另一个变量、传进函数、放进容器，都会**转移**所有权，原变量随即失效。

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1; // 所有权从 s1 移动（move）到 s2
    // println!("{}", s1); // ❌ 编译错误 E0382: borrow of moved value
    println!("{}", s2); // ✅
}
```

> [!note] 为什么不是浅拷贝
> `String` 由「指针 + 长度 + 容量」组成，如果像 C++ 那样浅拷贝，`s1` 和 `s2` 会指向同一块堆内存，析构时就会**重复释放**。Rust 的做法是：复制栈上的三个字段，然后让 `s1` 失效——这就是移动。

## 克隆：显式复制堆数据

需要两份独立数据时用 `.clone()`，代价是真实的内存复制，**不会偷偷发生**。

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1.clone(); // 深拷贝，两个独立的所有者
    println!("{} {}", s1, s2); // ✅ 都能用
}
```

## Copy：栈上的小类型直接复制

实现了 `Copy` trait 的类型（整数、`bool`、`char`、`f64`、只含 `Copy` 字段的数组/元组）在赋值时是**复制**而不是移动：

```rust
fn main() {
    let a = 42;
    let b = a; // i32 是 Copy，a 仍然有效
    println!("{} {}", a, b);

    let arr = [1, 2, 3];
    let arr2 = arr; // [i32; 3] 是 Copy
    println!("{:?} {:?}", arr, arr2);
}
```

规则：**能实现 `Copy` 的类型一定也能实现 `Clone`，反之不成立**；`String`、`Vec<T>` 管理堆内存，只能是 `Clone`。

## 函数传参与返回同样会移动

```rust
fn consume(s: String) -> String {
    // s 的所有权进入函数
    s // 返回时所有权交给调用者
}

fn main() {
    let s = String::from("hello");
    let s = consume(s); // 所有权先移出再移回
    println!("{}", s);
}
```

如果只是「用一下」，不要转移所有权，而是**借用**：见 [[06-借用与引用|借用与引用]]。

## 所有权与作用域：`drop` 的时机

- 变量在**声明之后**才可用，在**离开作用域**时按**声明的逆序**释放。
- `Drop` trait 让你自定义释放逻辑，详见 [[20-智能指针|智能指针]]。

```rust
fn main() {
    let a = String::from("a");
    let b = String::from("b"); // 先释放 b，再释放 a
    println!("{} {}", a, b);
}
```

## 常见错误与解决

| 错误 | 原因 | 解决 |
| --- | --- | --- |
| `E0382: borrow of moved value` | 值已被移动 | 用 `.clone()`、改用引用 `&T`、或调整所有权顺序 |
| `E0505: cannot move out of ... because it is borrowed` | 借用期间移动 | 先结束借用（缩小作用域），再移动 |
| `E0507: cannot move out of borrowed content` | 想从 `&T` 里移出字段 | 用 `Option::take`、`std::mem::take` 或 `Clone` |
| 函数返回引用但数据在函数内创建 | 返回了悬垂引用 | 返回拥有所有权的值，或用生命周期标注（[[17-生命周期|生命周期]]） |
