# 字符串：`str` 与 `String`

> [!abstract] 一句话
> Rust 的字符串**永远**是合法 UTF-8：`&str` 借用一段字节序列，`String` 拥有这块堆内存且可以增长，两者可零拷贝互转。

## 为什么需要它

各语言的字符串模型差别很大，对比一下最快理解 Rust 的取舍：

| 语言 | 表示 | 代价 |
| --- | --- | --- |
| C | `char*` + `\0` | 长度自己管，编码靠约定 |
| Java / C# | UTF-16 不可变对象 | 非 ASCII 占双倍内存，索引取到 UTF-16 单元 |
| Rust | `&str` / `String`，恒为 UTF-8 | 不能按字符下标，换来零拷贝切片与正确性 |

Rust 在类型层面保证内容始终合法 UTF-8，这是后面所有规则（不能索引、切片按字节）的根源。

## 两种字符串类型

```rust
fn main() {
    let literal: &'static str = "编译期写进二进制"; // 借用只读数据
    let mut owned: String = String::from("堆上");   // 拥有，可增长
    owned.push_str("，可以变长");
    assert_eq!(&owned[..], owned.as_str());
    println!("{} / {}", literal, owned);
}
```

`str` 是未定大小的字节序列（只以 `&str` 出现，`&str` = 指针 + 长度）；`String` 本质是 `Vec<u8>` 加上「内容必须合法 UTF-8」的不变式（指针 + 长度 + 容量）。字面量是 `&'static str`，需要修改或返回所有权时才用 `String`。

## UTF-8：字节、字符、字素

```rust
fn main() {
    let s = "a中é";
    assert_eq!(s.len(), 6);           // 字节数：1 + 3 + 2
    assert_eq!(s.chars().count(), 3); // 码位个数
    assert_eq!(&s.as_bytes()[..3], &[0x61, 0xE4, 0xB8]); // 一个汉字 3 字节

    let composed = "é";           // U+00E9，1 个 char
    assert_eq!(composed.chars().count(), 1);
    assert_eq!("e\u{0301}".chars().count(), 2); // e + 组合重音，2 个 char
}
```

「一个字符」有三个层次：**字节**（`s.len()`）、**码位**（`s.chars()`）、**字素簇**（用户眼中的「一个字」，可能是多个码位，标准库不提供 API，需外部 crate）。混用这三层是字符串 bug 的主要来源。

## 为什么不能按索引取字符

```text
let s = String::from("你好");
let c = s[0]; // ❌ E0277: the type `String` cannot be indexed by `{integer}`
```

- 若返回第 i 个**字符**，必须从头扫描字节，实际是 O(n)，却被写成看起来 O(1) 的下标。
- 若返回第 i 个**字节**，得到半个字符，直接破坏「恒为合法 UTF-8」的保证。

所以标准库不实现 `Index<usize>`，逼你显式写清代价：

```rust
fn main() {
    let s = String::from("你好，世界");
    assert_eq!(s.chars().nth(1), Some('好'));   // O(n) 扫描
    let chars: Vec<char> = s.chars().collect(); // 需要频繁随机访问就先转 Vec<char>
    assert_eq!(chars[1], '好');
}
```

## 切片按字节，必须落在字符边界

```rust
fn main() {
    let s = "中文abc";
    assert_eq!(&s[..3], "中"); // 「中」占 3 字节
    assert_eq!(&s[3..], "文abc");
    // &s[..1] 会 panic: byte index 1 is not a char boundary
    let i = s.char_indices().nth(1).map(|(i, _)| i).unwrap_or(s.len());
    assert_eq!(&s[..i], "中"); // 用 char_indices 找安全边界
}
```

## 拼接：三种方式

```rust
fn main() {
    let mut s = String::from("hello");
    s.push_str(" world"); // 1. 原地追加，最省分配
    s.push('!');
    assert_eq!(s, "hello world!");

    let a = String::from("foo");
    let b = String::from("bar");
    let c = a + &b; // 2. + 消耗左值，右侧接收 &str
    assert_eq!(c, "foobar");
    assert_eq!(b, "bar"); // b 未被移动

    assert_eq!(format!("{}-{}", c, b), "foobar-bar"); // 3. format! 不消耗入参
}
```

`push_str` / `push` 原地改、分摊 O(1)；`+` 会**移动**左值并复用它的缓冲；`format!` 谁都不移动、可读性最好，适合多个值混合拼接。

## 常用方法

| 方法 | 说明 |
| --- | --- |
| `chars` / `bytes` | 迭代码位 / 迭代原始字节 |
| `char_indices` | 迭代「字节下标 + 字符」，用于安全切片 |
| `as_bytes` / `as_str` | 借出字节切片 / 借出 `&str` |
| `push_str` / `push` | 追加 `&str` / 追加单个 `char` |
| `insert` / `remove` | 按字节位置插入或删除，非边界会 panic |
| `contains` / `starts_with` | 判断包含子串 / 以某串开头 |
| `trim` / `replace` | 去掉两端空白 / 替换全部出现 |
| `to_uppercase` / `parse::<T>` | 转换为大写 / 解析成其他类型 |

## 常见错误与解决

| 错误 / 现象 | 原因 | 解决 |
| --- | --- | --- |
| `E0277` 索引字符串 | `str` 没实现 `Index<usize>` | 用 `chars()` / `char_indices()`，或先转 `Vec<char>` |
| `byte index ... is not a char boundary` | 切片切在字符中间 | 用 `char_indices()` 找边界 |
| `E0382: borrow of moved value` | 用了 `+` 之后又用左值 | 改用 `format!` 或先 `clone()` |
