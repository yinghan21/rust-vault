# 借用与引用

> [!abstract] 一句话
> 借用就是「借来看看」：`&T` 只读、可以同时存在多个；`&mut T` 可写、在它的生命周期内**独占**。

## 为什么需要它

[[05-所有权|所有权]]解决了「谁负责释放」，但如果每次调用函数都把值交出去，用起来会疯掉——`fn 打印(s: String)` 打完就把值消耗了。C 用指针拷来拷去，代价是野指针和悬垂引用；C++ 引入引用但仍有 `delete` 后继续用的问题；Java 干脆把对象都放堆上让 GC 管。Rust 的折中方案是**借用检查**：引用指向的数据一定活得更久，编译器在编译期就证明这一点，运行时没有引用计数、没有 GC。

借用的第二条价值是**别名控制**：允许「多个只读」或「一个可写」，但绝不允许「边读边写」。这直接消掉了数据竞争的一半来源，也是 [[21-并发编程|并发编程]]里 `Send`/`Sync` 规则的基础。

## 核心规则

### `&T` 与 `&mut T`

| 形式 | 名字 | 能力 | 副本数量 |
| --- | --- | --- | --- |
| `&T` | 共享引用（不可变借用） | 只能读 | 任意多个可以同时存在 |
| `&mut T` | 可变引用（可变借用） | 可读可写 | 同一时刻**只能有一个** |

规则原文只有一句：**在任意时刻，对同一份数据，要么有任意多个 `&T`，要么有恰好一个 `&mut T`，两者不能同时存在。**

### 借用不转移所有权

```rust
fn show(s: &str) {
    println!("{}", s); // s 只是借来的，函数结束不会释放底层数据
}

fn main() {
    let owned = String::from("hello");
    show(&owned);   // 借出
    show(&owned);   // 还能再借，因为 show 没有拿走所有权
    println!("{}", owned); // 依然可用
}
```

对比 `fn show(s: String)`：那个版本会移动，`owned` 之后失效（`E0382`）。

### 自动解引用与 `.` 方法调用

`&T` 上做 `*r` 是取值；而方法调用会自动加引用/解引用：`T` 上的方法可以直接在 `&T`、`&mut T` 上调用，不用写 `(*r).method()`。这也解释了为什么 `&String` 能调用 `String` 的方法，以及 `&Vec<T>` 能自动转成 `&[T]`（解引用强制转换，见 [[ops.Deref|Deref]]）。

### NLL：非词法生命周期

早期 Rust 里借用的结束点是**词法作用域结尾**；现在的 NLL（non-lexical lifetimes）按**最后一次使用**计算。所以下面这种「先借、用完、再改」的写法是合法的：

```rust
fn main() {
    let mut v = vec![1, 2, 3];
    let first = &v[0];
    println!("{}", first); // 最后一次使用 first
    v.push(4);             // NLL 认为借用已经结束，允许可变借用
}
```

如果 `println!` 之后还用到 `first`，借用就没结束，`v.push(4)` 报 `E0502`。**借用的存活区间由使用点决定，不是由变量声明位置决定**——这是读借用错误时最重要的一条直觉。

### 切片借用与迭代器失效

切片 `&v[..]`、`&s[a..b]` 是**借用**，所以持有切片期间不能修改原容器。C++ 里对应的问题是「迭代器失效」：`push_back` 可能重新分配内存，旧迭代器变成野指针，编译器不管；Rust 里这直接是编译错误。

修复思路永远是同一个：**先算完、结束借用，再修改**，或者**用索引而非切片**。

### 借用与所有权的配合原则

| 场景 | 选择 |
| --- | --- |
| 只是读一下 | `&T`（参数写 `&str` 而不是 `String`） |
| 需要就地修改 | `&mut T` |
| 需要把值留给自己 | 传所有权 `T`，或返回新值 |
| 要长期保存一份数据 | `.clone()` 或 `Rc`/`Arc`，见 [[20-智能指针|智能指针]] |
| 想把所有权交还给调用者 | 返回值 `-> T` |

一句话原则：**函数签名里能不拿所有权就不拿**。这能让调用者保留自己的值，也让 `&str` 这类借用类型能接受更多输入。

### 引用的有效期由谁保证

`fn first_word(s: &str) -> &str` 能编译，是因为**省略规则**把返回引用的生命周期绑到了唯一的输入引用上。多个输入引用时省略规则失效，必须显式标注——那是 [[17-生命周期|生命周期]]的主题，本篇只记住「返回引用必须有明确来源」。

## 代码示例

第一段演示两种借用与函数签名选择：

```rust
// 只读借用：不消耗调用者的值
fn total_len(items: &[String]) -> usize {
    items.iter().map(|s| s.len()).sum()
}

// 可变借用：就地修改
fn shout_all(items: &mut [String]) {
    for item in items.iter_mut() {
        item.push('!');
    }
}

fn main() {
    let mut words = vec![String::from("hi"), String::from("rust")];
    println!("总长度：{}", total_len(&words));

    shout_all(&mut words);
    assert_eq!(words, vec!["hi!".to_string(), "rust!".to_string()]);

    // 引用是 Copy 的，可以随意复制
    let r = &words[0];
    let r2 = r;
    assert_eq!(r, r2);
    assert_eq!(*r, "hi!");
}
```

第二段演示 NLL、切片借用与索引解法：

```rust
fn first_word(s: &str) -> &str {
    match s.find(' ') {
        Some(i) => &s[..i],
        None => s,
    }
}

fn main() {
    let mut v = vec![1, 2, 3, 4];

    // 1. NLL：借用在上次使用后结束
    let first = &v[0];
    println!("首元素：{}", first);
    v.push(5);

    // 2. 切片借用：先算完再修改
    let sum: i32 = {
        let slice = &v[1..];      // 借用被限制在块内
        slice.iter().sum()
    };
    v.push(sum);

    // 3. 用索引循环避免「读着改着」
    for i in 0..v.len() {
        v[i] += 1;
    }
    println!("{:?}", v);

    // 4. 返回借用：借用参数的切片
    assert_eq!(first_word("hello world"), "hello");
    assert_eq!(first_word("nospace"), "nospace");
}
```

下面这种写法**编译不过**，看错误信息时用它对照：

```text
let mut v = vec![1, 2, 3];
let r = &v[0];      // 不可变借用开始
v.push(4);          // ❌ E0502: cannot borrow `v` as mutable
println!("{}", r);  // 因为 r 还在用，借用没结束
```

## 常见错误与解决

| 错误 | 原因 | 解决 |
| --- | --- | --- |
| `E0502: cannot borrow as mutable because it is also borrowed as immutable` | 读借用还活着的时候想写 | 把读借用的最后一次使用提前，或用 `{ }` 缩小作用域 |
| `E0499: cannot borrow as mutable more than once at a time` | 同时存在两个 `&mut` | 分段使用，或用 `split_at_mut` 拿到互不重叠的两块 |
| `E0596: cannot borrow as mutable, as it is not declared as mutable` | 变量没加 `mut` | `let mut v = ...;` |
| `E0505: cannot move out of ... because it is borrowed` | 借用期间把值移走 | 先结束借用再移动，或改为借用传递 |
| `E0716: temporary value dropped while borrowed` | 借用了临时值 | 先用 `let` 绑定到变量，再借 |
| `E0106: missing lifetime specifier` | 多个输入引用，省略规则无法确定返回值的来源 | 显式标注生命周期 |
