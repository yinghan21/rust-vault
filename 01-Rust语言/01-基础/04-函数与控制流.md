# 函数与控制流

> [!abstract] 一句话
> Rust 的 `if`、`loop`、`match` 甚至代码块**都是表达式**，所以返回值不必依赖 `return`——把结果放在最后一行就行。

## 为什么需要它

C 和 Java 里 `if` 是语句，赋值得先声明再分支赋值；只有函数式语言习惯「一切皆表达式」。Rust 取了这个习惯：`let x = if c { 1 } else { 2 };` 合法，循环还能 `break 值` 直接产出结果。好处是**变量一经绑定就有初值**，不会出现「某个分支忘了赋值」的未初始化状态，编译器也就不需要一套复杂的「明确赋值分析」。

## 核心规则

### 定义函数

- 参数必须标类型；没有默认参数和可变参数，要「多个可选参数」就传结构体，见 [[07-结构体|结构体]]。
- 没有 `->` 时返回类型是 `()`，函数体结尾不能留下非 `()` 的表达式。
- 函数名用蛇形 `snake_case`，其他写法触发 `non_snake_case` 警告。

### 语句与表达式

- **语句**完成一个动作，求值为 `()`：`let x = 1;`、`println!("hi");`。
- **表达式**求出一个值：`1 + 2`、`if b { 1 } else { 2 }`、`{ let y = 3; y * 2 }`。

区别只在**结尾有没有分号**：`{ let y = 3; y * 2 }` 的值是 `6`，写成 `y * 2;` 就退化成语句，块的值成了 `()`。函数体最后一行多写一个分号，就会得到 `E0308`。赋值本身是语句不是表达式，所以 `let a = (let b = 2);` 不合法——这点和 C 的 `a = b = 2` 不同。

### `if` / `else if` / `else`

条件必须是 `bool`，没有「非零即真」，`if 1 { }` 直接报 `E0308`。作为表达式时所有分支必须返回同一类型；缺 `else` 时整个 `if` 的值是 `()`，不能赋给 `i32`。

### `loop` / `while` / `for`

| 形式 | 何时用 | 注意 |
| --- | --- | --- |
| `loop { }` | 次数未知，靠 `break` 退出 | 只有 `loop` 能 `break 值` |
| `while 条件 { }` | 有明确退出条件 | 条件必须是 `bool` |
| `for x in 迭代器 { }` | **首选** | `0..n` 左闭右开，`0..=n` 含右端 |

`for` 基于 `IntoIterator`，既不会越界也不会忘写 `i += 1`，是遍历集合的默认选择；迭代器组合能力见 [[18-迭代器|迭代器]]。多层嵌套时给循环起标签 `'outer:`，`break 'outer` 一次跳出多层，`continue 'outer` 同理。标签以 `'` 开头，形似生命周期标注但语义不同。

### 提前返回与 `?`

- `return expr;`：**无条件**立刻返回，`expr` 类型必须等于函数返回类型，不做任何转换。
- `expr?`：**有条件**返回；`expr` 必须是 `Result` 或 `Option`，`Ok(v)` 取出 `v` 继续执行，`Err(e)` 立刻 `return Err(e.into())`——中间多做一次 `From` 转换。

所以「`?` 会转换错误类型、`return` 不会」是两者最实质的差别。完整机制与自定义错误类型见 [[11-错误处理|错误处理]]。

## 代码示例

函数返回值、提前返回与 `?` 放在一起对照：

```rust
// 末尾的 Some(a / b) 就是返回值；有多处出口时提前返回更清楚
fn safe_div(a: i32, b: i32) -> Option<i32> {
    if b == 0 {
        return None;
    }
    Some(a / b)
}

// ? 遇到 Err 立刻返回，并做一次 From 转换
fn twice(text: &str) -> Result<i32, std::num::ParseIntError> {
    let n: i32 = text.parse()?;
    Ok(n * 2)
}

fn main() {
    assert_eq!(safe_div(6, 3), Some(2));
    assert_eq!(safe_div(6, 0), None);
    assert_eq!(twice("21"), Ok(42));
    assert!(twice("abc").is_err());

    // 代码块也是表达式，值是最后一行
    let v = {
        let base = 10;
        base * 2
    };
    assert_eq!(v, 20);
}
```

三种循环、`continue` 与带标签的 `break`：

```rust
fn main() {
    // loop：靠 break 带出结果
    let mut i = 0;
    let answer = loop {
        i += 1;
        if i * i > 100 {
            break i;
        }
    };
    assert_eq!(answer, 11);

    // while：条件为假就退出
    let mut n = 3;
    while n > 0 {
        n -= 1;
    }
    assert_eq!(n, 0);

    // for：遍历区间，continue 跳过本轮
    let mut evens = Vec::new();
    for k in 1..=10 {
        if k % 2 != 0 {
            continue;
        }
        evens.push(k);
    }
    assert_eq!(evens, vec![2, 4, 6, 8, 10]);

    // 带标签，一次跳出两层
    let mut found = None;
    'outer: for a in 0..5 {
        for b in 0..5 {
            if a * b == 6 {
                found = Some((a, b));
                break 'outer;
            }
        }
    }
    assert_eq!(found, Some((2, 3)));
}
```

## 常见错误与解决

| 错误 | 原因 | 解决 |
| --- | --- | --- |
| `E0308: mismatched types` 指向函数最后一行 | 多写了 `;`，返回值变成 `()` | 去掉结尾分号，或改用 `return` |
| `E0308` + `expected bool, found integer` | 把整数当条件 | 写显式比较，如 `if n != 0` |
| `E0308` 指向 `if` 各分支 | 分支返回类型不一致 | 让每个分支产出同一类型 |
| `E0061: this function takes 2 arguments` | 参数个数不对 | 补齐参数；Rust 没有默认参数 |
| `E0277: the ? operator can only be used in ...` | 在返回 `()` 的函数里用了 `?` | 把返回类型改成 `Result`，或就地 `match` |

## 练习

1. 写 `fn classify(n: i32) -> &'static str`，返回 `"负数"`、`"零"`、`"正数"`，函数体是一个 `if` 表达式，不写 `return`。
2. 用带标签的 `loop` 找出第一个满足 `x * x > 1000` 的整数，让 `loop` 直接产出它。
3. 把 `fn read_num(s: &str) -> i32` 改成 `Result` 版本，分别用 `match` 和 `?` 实现，说明 `?` 版本为什么更短。
