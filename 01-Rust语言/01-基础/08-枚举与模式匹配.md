# 枚举与模式匹配

> [!abstract] 一句话
> 枚举（`enum`）的每个变体可以携带不同数据，`match` 则按模式把值拆开并**强制穷尽**——少处理一种情况就编译不过。

## 为什么需要它

C 的 `enum` 只是整数别名，配 `switch` 还得自己记住所有取值；Java 的 `enum` 各变体字段类型必须一致，表达「成功/失败/进行中」时常退化成几个 `boolean` 加注释；Python 里同一字段一会儿 `None`、一会儿字符串，只能靠约定。Rust 把「标签 + 数据」放进同一个类型，再用 `match` 消费：非法状态构造不出来，漏掉的分支编译器直接指出来。`Option<T>` 就是用枚举表达「可能没有值」的标准库范例（[[option.Option|Option]]）。

## 核心规则

### 带数据的枚举

```rust
#[derive(Debug)]
enum Shape {
    Circle { radius: f64 }, // 结构体式变体
    Rect(f64, f64),         // 元组式变体
    Empty,                  // 单元式变体
}

fn area(shape: &Shape) -> f64 {
    match shape {
        Shape::Circle { radius } => std::f64::consts::PI * radius * radius,
        Shape::Rect(w, h) => w * h,
        Shape::Empty => 0.0, // 少写任何一个变体都会报 E0004
    }
}

fn main() {
    let shapes = [Shape::Circle { radius: 1.0 }, Shape::Rect(2.0, 3.0), Shape::Empty];
    for s in &shapes {
        println!("{:?} 面积 {:.2}", s, area(s));
    }
}
```

- 三个变体的字段可以完全不同：`Circle` 用具名字段、`Rect` 用位置字段、`Empty` 没有字段。
- 变体的构造路径是 `Shape::Circle`（`use Shape::*;` 后能简写，公开 API 里建议写全）；枚举也能有 `impl` 方法（[[09-方法与 impl|方法与 impl]]），所以「数据 + 行为」不必拆成两个类型。

### `match` 的穷尽性

- 所有分支的**类型必须一致**，整个 `match` 表达式的值就是分支的返回值。
- 编译器要求覆盖全部可能性：漏掉枚举变体报 `E0004`。这也意味着**新增变体后所有 `match` 一起报错**，逼你逐个审阅。
- `_ =>` 能兜底，但会吞掉未来新增的变体，只在取值范围确实开放时用；分支按顺序匹配，先具体后宽泛，否则后面的分支永远走不到（`unreachable_patterns` 警告）。

### 常见模式

| 模式 | 写法示例 | 说明 |
| --- | --- | --- |
| 字面量 | `0`、`"ok"` | 精确匹配 |
| 范围 | `1..=9`、`'a'..='z'` | 闭区间，用于整数与 `char` |
| 绑定 | `x @ 10..=99` | 匹配的同时把值绑到 `x` |
| 解构 | `Shape::Rect(w, h)`、`Some(v)` | 拆开枚举、结构体、元组 |
| 忽略 | `_`、`(_, y)` | 不关心该位置 |
| 守卫 | `x if x % 2 == 0` | 附加条件，可写任意表达式 |
| 或 | `1 \| 2`、`Some(1 \| 2)` | 任一成立即可 |

默认绑定**按值移动**，想借用就写 `ref`/`ref mut` 或直接匹配 `&value`；移动规则见 [[05-所有权|所有权]]。

### `if let` / `while let` / `let else`

- `if let Some(v) = opt { .. }`：只关心一种情况，等价于只有一个分支的 `match`；可以再跟 `else`。
- `while let Some(v) = iter.next() { .. }`：条件就是「模式匹配成功」，常用于手写循环。
- `let Some(v) = opt else { return };`：在函数开头**提前返回**，让主逻辑保持平坦；`else` 块必须发散（`return`/`break`/`panic!`）。
- 普通 `let Some(v) = opt;` 会报 `E0005`：可失败的模式不能直接绑定。

### 用枚举替代状态标志

- 坏味道：`struct Job { running: bool, failed: bool, done: bool }` 有 8 种组合，其中一半非法，读代码得靠注释猜。
- 好做法：`enum State { Idle, Running { pid: u32 }, Done, Failed { reason: String } }`，非法状态构造不出来，`match` 又会提醒你处理新变体；状态转移写成 `fn advance(&mut self)`，用 `std::mem::replace` 或 `Option::take` 取出旧状态，既不用 `Clone` 也不会留下半初始化值。

## 代码示例

```rust
fn parse_port(input: Option<&str>) -> Option<u16> {
    // let ... else：不满足就提前退出，避免层层缩进
    let Some(text) = input else { return None };
    text.trim().parse::<u16>().ok()
}

fn describe(n: u8) -> String {
    match n {
        0 => "零".to_string(),
        1..=9 => "个位数".to_string(), // 范围模式
        x @ 10..=99 if x % 2 == 0 => format!("{x} 是两位数偶数"), // 绑定 + 守卫
        x @ 10..=99 => format!("{x} 是两位数奇数"),
        x => format!("{x} 超过两位"),
    }
}

fn main() {
    // if let：只关心成功的那一支
    if let Some(port) = parse_port(Some(" 8080 ")) {
        println!("端口 {port}");
    }
    println!("{}", parse_port(None).unwrap_or(0)); // None 用默认值兜底

    // while let：栈非空就继续弹
    let mut stack = vec![1, 2, 3];
    let mut total = 0;
    while let Some(top) = stack.pop() {
        total += top;
    }
    println!("总和 = {total}");

    for n in [0u8, 7, 12, 42, 200] {
        println!("{}", describe(n));
    }
    // matches!：只判断不取值
    println!("{}", matches!(parse_port(Some("80")), Some(80)));
}
```

## 常见错误与解决

| 错误 / 现象 | 原因 | 解决 |
| --- | --- | --- |
| `E0004: non-exhaustive patterns: 'Shape::Empty' not covered` | `match` 漏了变体 | 补全所有变体，或加 `_ =>` 兜底 |
| `E0005: refutable pattern in local binding` | `let Some(v) = opt;` 用了可能失败的模式 | 改用 `if let`、`let ... else` 或 `match` |
| `E0382: borrow of moved value` | 按值匹配把字段移走了，之后又用原值 | 匹配 `&shape`，或用 `ref` 绑定 |
| `E0509: cannot move out of type 'Job', which implements the 'Drop' trait` | 从实现了 `Drop` 的类型里移出字段 | 改为借用匹配，或用 `Option::take` |
| 运行时 `called 'Option::unwrap()' on a 'None' value` | 直接对 `None` 调 `unwrap` | 用 `match`/`if let`/`unwrap_or` 兜底 |

## 练习

1. 定义 `enum Command { Quit, Move { x: i32, y: i32 }, Write(String) }`，写 `fn run(c: &Command)`，用 `match` 打印每种命令。
2. 用 `while let Some(x) = stack.pop()` 把栈清空并求和，再改写成 `for` 循环，比较可读性。
3. 把 `struct Order { paid: bool, shipped: bool, refunded: bool }` 改写成枚举状态，并写 `fn advance(&mut self)` 推进到下一状态。
