# 项目：命令行工具 mywc

## 目标

用 `clap` 4 的 derive 写一个行为接近 `wc` 的 `mywc`：支持 `-l`/`-w`/`-c`、多文件与标准输入；单个文件失败不中断其余文件，但退出码非 0。做完这一篇，`clap` 的 derive 用法、`BufRead` 流式读取、`anyhow` 错误上下文和 `assert_cmd` 集成测试四条线都会走通一遍。

## 技术栈

| 用途 | crate / 标准库 |
| --- | --- |
| 参数解析、`--help`、版本号 | `clap` 4（`derive` 特性） |
| 错误上下文与错误链 | `anyhow` |
| 文件打开与流式读取 | `std::fs::File`、`std::io::BufRead` |
| 退出码与集成测试 | `std::process::ExitCode`、`assert_cmd` + `predicates` |

## 第 1 步：初始化项目

```bash
cargo new mywc --bin
cd mywc
cargo add clap --features derive
cargo add anyhow
cargo add --dev assert_cmd predicates
```

`Cargo.toml` 的完整依赖片段（发布前再补 `repository`、`keywords` 与 `LICENSE` 文件）：

```toml
[package]

[dev-dependencies]

```

## 第 2 步：用 derive 描述命令行

```rust
use clap::Parser;
use std::path::PathBuf;

/// 统计文件的行数、词数与字节数
#[derive(Parser, Debug)]
#[command(name = "mywc", version, about)]
struct Cli {
    /// 只输出行数
    #[arg(short = 'l', long)]
    lines: bool,
    /// 只输出词数
    #[arg(short = 'w', long)]
    words: bool,
    /// 只输出字节数
    #[arg(short = 'c', long = "bytes")]
    bytes: bool,
    /// 待统计的文件；不传则读标准输入
    files: Vec<PathBuf>,
}
```

`Vec<PathBuf>` 收走剩余参数，所以不用写 `--`；长选项由字段名推导，`#[arg]` 只覆盖短选项和 `bytes` 的别名。三个开关都为假时视为“三个都要”，这个判断放在打印逻辑里。

## 第 3 步：核心统计逻辑

```rust
use std::io::{self, BufRead, BufReader, Read};

#[derive(Debug, Default, PartialEq, Eq)]
pub struct Stats {
    pub lines: u64,
    pub words: u64,
    pub bytes: u64,
}

/// 逐行读取、边读边计数：内存只与最长一行有关
pub fn count_reader<R: Read>(reader: R) -> io::Result<Stats> {
    let mut stats = Stats::default();
    let mut reader = BufReader::with_capacity(64 * 1024, reader);
    let mut line = Vec::with_capacity(256);
    loop {
        line.clear();
        let n = reader.read_until(b'\n', &mut line)?;
        if n == 0 {
            break; // 读到 EOF
        }
        stats.lines += 1;
        stats.bytes += n as u64;
        stats.words += line
            .split(|b| b.is_ascii_whitespace())
            .filter(|w| !w.is_empty())
            .count() as u64;
    }
    Ok(stats)
}
```

`read_until` 的返回值**包含** `\n`，直接累加就是字节数；末行没有换行也算一行，与 `wc` 一致。按字节切词，`is_ascii_whitespace()` 覆盖空格、`\t`、`\r`，CRLF 文件不会多算词；也不要在循环里 `read_to_string` 整个文件。

## 第 4 步：错误处理与输出

```rust
use anyhow::{Context, Result};
use std::fs::File;
use std::path::{Path, PathBuf};
use std::process::ExitCode;

fn main() -> Result<ExitCode> {
    run() // 出错时 anyhow 打印 "Error: ..." 并让进程以 1 退出
}

fn run() -> Result<ExitCode> {
    let cli = Cli::parse();
    let inputs = if cli.files.is_empty() { vec![PathBuf::from("-")] } else { cli.files.clone() };
    let all = !cli.lines && !cli.words && !cli.bytes;
    let mut failed = false;
    for path in &inputs {
        let Ok(stats) = count_path(path) else {
            eprintln!("mywc: 跳过 {}", path.display()); // 单个文件失败不中断其余文件
            failed = true;
            continue;
        };
        if all || cli.lines { print!("{:>8}", stats.lines); }
        if all || cli.words { print!("{:>8}", stats.words); }
        if all || cli.bytes { print!("{:>8}", stats.bytes); }
        println!(" {}", path.display());
    }
    Ok(if failed { ExitCode::FAILURE } else { ExitCode::SUCCESS })
}

fn count_path(path: &Path) -> Result<Stats> {
    if path == Path::new("-") {
        return count_reader(std::io::stdin().lock()).context("读取标准输入失败");
    }
    let file = File::open(path).with_context(|| format!("无法打开 {}", path.display()))?;
    count_reader(file).with_context(|| format!("读取 {} 失败", path.display()))
}
```

`with_context` 把 `io::Error` 包成带文件名的 `anyhow::Error`，`?` 负责向上抛。想自己控制错误前缀（`mywc: ...`）就把 `main` 改成返回 `ExitCode` 并 `match` 一下 `run()`。

## 第 5 步：测试与发布

```rust
// tests/cli.rs：真正跑二进制，验证 clap 接线与退出码
use assert_cmd::Command;
use predicates::prelude::*;

#[test]
fn 文件不存在时退出码非零() {
    let mut cmd = Command::cargo_bin("mywc").unwrap();
    cmd.arg("不存在.txt").arg("-l");
    cmd.assert().failure().stderr(predicate::str::contains("不存在.txt"));
}
```

纯逻辑用 `#[cfg(test)] mod tests` 直接测 `count_reader`：`count_reader("hello world\nrust\n")` 应等于 `Stats { lines: 2, words: 3, bytes: 17 }`，空输入应等于 `Stats::default()`。

发布前逐条执行：`cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`、`cargo test`、`cargo publish --dry-run`（打包但不上传）、`cargo install --path .`（本地装完再试一遍）。版本号走语义化版本，`license` 与 `license-file` 只能二选一。

## 运行与验证

```bash
cargo run -- Cargo.toml
cargo run -- -l -w src/main.rs
printf 'hello rust\n' | cargo run --
```

输出是右对齐的数字列加文件名；多文件时每个文件一行，`-l` 只给一列。

## 扩展方向

1. 加 `-L` 统计最长行、`--json` 输出结构化结果（`serde` + `serde_json`）。
2. 用 `walkdir` 递归目录做成 `mywc -r src/`，并对结果排序。
3. 用 `--threads N` 把多文件分片到 `std::thread` 并行统计，见 [[21-并发编程|并发编程]]；用 `criterion` 对比逐行读取与 `memchr` 批量扫描的吞吐，见 [[26-性能与优化|性能与优化]]。
