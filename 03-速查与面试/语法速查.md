# 语法速查

> [!abstract] 一句话
> 每行一个「想写什么 → 最小写法」，按主题分组；需要展开时跳到对应的学习笔记。

## 变量与绑定

| 条目 | 说明 |
| --- | --- |
| `let x = 1;` | 不可变绑定，类型从右侧推断。 |
| `let mut x = 1;` | 可变绑定，只有它能被重新赋值。 |
| `let x: u8 = 5;` | 显式类型标注，写在变量名后。 |
| `let x = 5; let x = x + 1;` | 遮蔽（shadowing），新变量可换类型。 |
| `const MAX: u32 = 100;` | 编译期常量，必须写类型，可放任意作用域。 |
| `static GREETING: &str = "hi";` | 全局静态量，有固定地址，必须写类型。 |
| `static mut N: i32 = 0;` | 可变静态量，读写都在 `unsafe` 里。 |
| `let (a, b) = (1, 2);` | 解构式绑定，模式写在 `let` 左边。 |
| `let Point { x, y } = p;` | 用结构体模式一次取出多个字段。 |
| `let _ = compute();` | 用 `_` 丢弃返回值，不影响所有权语义以外的检查。 |
| `let s = String::from("a"); let t = s;` | 移动（move），此后 `s` 不可用。 |
| `let t = s.clone();` | 显式深拷贝，`s` 仍可用。 |
| `let y = &x;` | 不可变借用，同一时刻可有多个。 |
| `let y = &mut x;` | 可变借用，独占，同一时刻只能有一个。 |

## 基本类型

| 条目 | 说明 |
| --- | --- |
| `i8` `i16` `i32` `i64` `i128` `isize` | 有符号整数，默认 `i32`；`isize` 随平台（64 位下 64 位）。 |
| `u8` `u16` `u32` `u64` `u128` `usize` | 无符号整数，索引与长度用 `usize`。 |
| `f32` `f64` | 浮点数，默认 `f64`；不实现 `Eq`/`Ord`。 |
| `bool` | `true` / `false`，条件必须是它，不能用 `0`/`1`。 |
| `char` | 单个 Unicode 标量值，4 字节，单引号 `'中'`。 |
| `()` | 单元类型，函数无返回值时的返回类型。 |
| `(i32, &str)` | 元组，定长异构，用 `t.0` 访问。 |
| `[u8; 4]` | 数组，定长同构，长度是类型的一部分。 |
| `&[u8]` | 切片引用，带长度的视图，可指向数组或 `Vec`。 |
| `&str` | 字符串切片，UTF-8，不可增长。 |
| `String` | 可增长的堆字符串，`&String` 可自动转为 `&str`。 |
| `Option<T>` | 可能没有值，替代 `null`。 |
| `Result<T, E>` | 可能失败，替代异常。 |
| `Vec<T>` | 可增长数组，用 `vec![]` 或 `Vec::new()`。 |
| `Box<T>` | 堆上唯一所有权指针，用于递归类型或 `dyn`。 |

## 类型转换

| 条目 | 说明 |
| --- | --- |
| `x as u64` | 数值原生转换，可能截断或变号，不报错。 |
| `u32::from(byte)` | 无损且保证成功的转换，来自 `From`。 |
| `<u8 as TryFrom<u32>>::try_from(n)?` | 可能失败的转换，返回 `Result`。 |
| `s.parse::<i32>()?` | 字符串转数值，靠 `FromStr`。 |
| `n.to_string()` | 任意实现了 `Display` 的类型转 `String`。 |
| `&s[..]` / `s.as_str()` | `String` 转 `&str`。 |
| `s.to_owned()` | `&str` 转 `String`（`Clone` 语义）。 |
| `String::from(x)` / `x.into()` | 用 `From`/`Into` 构造目标类型。 |
| `arr.iter().collect::<Vec<_>>()` | 迭代器转集合，靠 `FromIterator`。 |
| `&*boxed` | 解引用强制转换，`Box<T>` 当 `&T` 用。 |

## 控制流

| 条目 | 说明 |
| --- | --- |
| `if c { } else if d { } else { }` | 条件分支，`c` 必须是 `bool`。 |
| `let n = if c { 1 } else { 2 };` | `if` 是表达式，可返回值。 |
| `match x { 0 => a, 1..=9 => b, _ => c }` | 模式匹配，必须覆盖所有情况。 |
| `match x { n if n < 0 => ..., _ => ... }` | 加守卫（guard）做额外判断。 |
| `if let Some(v) = opt { }` | 单分支模式匹配，省掉 `_ => {}`。 |
| `if let Some(v) = opt { } else { }` | `if let` 带 `else`，`else` 里拿不到 `v`。 |
| `let Some(v) = opt else { return };` | let-else，不匹配就走发散分支。 |
| `while c { }` | 条件循环。 |
| `while let Some(v) = it.next() { }` | 按模式持续取值直到不匹配。 |
| `loop { break; }` | 无限循环，`break` 可带值返回。 |
| `for i in 0..10 { }` | 右开区间，`0..=9` 为闭区间。 |
| `for v in &vec { }` | 遍历借用，不消耗 `vec`。 |
| `for (i, v) in vec.iter().enumerate() { }` | 同时拿下标和元素。 |
| `'outer: loop { break 'outer; }` | 标签，用于跳出多层循环。 |
| `return v;` | 提前返回，函数内任意位置可用。 |

## 函数与闭包

| 条目 | 说明 |
| --- | --- |
| `fn add(a: i32, b: i32) -> i32 { a + b }` | 参数必须标类型，末表达式即返回值。 |
| `fn log(msg: &str) { }` | 不写 `->` 等价于返回 `()`。 |
| `fn first(v: &[i32]) -> Option<i32> { v.first().copied() }` | 用 `Option` 表示可能无结果。 |
| `fn run() -> Result<(), Box<dyn std::error::Error>>` | 想在 `main`/函数里用 `?` 时的返回类型。 |
| `fn f<T: Clone>(x: T) -> T { x.clone() }` | 泛型函数，约束写在尖括号里。 |
| `fn f() -> impl Iterator<Item = i32> { 0..3 }` | 返回不透明类型，不暴露具体类型名。 |
| `\|a, b\| a + b` | 闭包，参数类型和返回类型通常可推断。 |
| `move \|x\| x + n` | 按值捕获外部变量。 |
| `let f: fn(i32) -> i32 = double;` | 函数指针，只能指向不捕获环境的函数。 |
| `fn apply<F: Fn(i32) -> i32>(f: F, x: i32) -> i32 { f(x) }` | 以 `Fn`/`FnMut`/`FnOnce` 接收闭包。 |

## 结构体

| 条目 | 说明 |
| --- | --- |
| `struct P { x: i32, y: i32 }` | 具名字段结构体。 |
| `struct Meter(i32);` | 元组结构体，用 `m.0` 访问。 |
| `struct Unit;` | 单元结构体，只做类型标记。 |
| `let p = P { x: 1, y: 2 };` | 逐字段构造，字段名必须写全。 |
| `let p = P { x, ..Default::default() };` | 结构体更新语法，剩余字段取自另一个值。 |
| `impl P { fn new(x: i32, y: i32) -> Self { Self { x, y } } }` | 关联函数，无 `self`，用 `P::new` 调用。 |
| `impl P { fn norm(&self) -> i32 { self.x + self.y } }` | 方法，`&self` 借用调用者。 |
| `impl P { fn shift(&mut self, d: i32) { self.x += d; } }` | 可变方法，要求 `&mut self`。 |
| `impl P { fn into_x(self) -> i32 { self.x } }` | 消耗 `self` 的方法，调用后原值失效。 |
| `#[derive(Debug, Clone, PartialEq)]` | 派生常用 trait，减少手写样板。 |
| `println!("{:?}", p);` | 用 `Debug` 打印，需要 `#[derive(Debug)]`。 |
| `#[derive(Default)]` + `P::default()` | 派生零值构造。 |
| `Field: i32` 前加 `pub` | 字段可见性单独控制，默认私有。 |

## 枚举

| 条目 | 说明 |
| --- | --- |
| `enum Color { Red, Green }` | 单元变体枚举，只能取列举的值。 |
| `enum Shape { Circle(f64), Rect { w: f64, h: f64 } }` | 变体可带元组或具名字段数据。 |
| `enum Msg { Quit, Move { x: i32 }, Text(String) }` | 各变体数据完全不同，等价于带标签的联合体。 |
| `impl Color { fn name(&self) -> &str { "red" } }` | 枚举也能有 `impl` 块。 |
| `Color::Red as u8` | 只有无数据的枚举才能转整数。 |
| `#[derive(Debug, Clone, Copy)]` | 枚举常用派生。 |
| `Option<T>` / `Result<T, E>` | 标准库里最重要的两个枚举。 |
| `#[non_exhaustive]` | 标记枚举可能新增变体，下游必须留 `_`。 |

## 模式匹配

| 条目 | 说明 |
| --- | --- |
| `match v { 1 \| 2 => a, _ => b }` | 多个模式用 `\|` 连接。 |
| `match v { 1..=5 => a, _ => b }` | 范围模式，只用于可比较的标量。 |
| `match p { P { x, y: 0 } => a, _ => b }` | 解构结构体，字面量直接匹配。 |
| `match p { P { x, .. } => a }` | `..` 忽略剩余字段。 |
| `match e { Some(v) => v, None => 0 }` | 解构枚举变体并绑定内部值。 |
| `match n { x @ 1..=5 => x, _ => 0 }` | `@` 绑定同时做范围判断。 |
| `match r { Ok(v) \| Err(v) => v }` | `\|` 要求各分支绑定同名同类型。 |
| `match s { ref v => ... }` | 显式按引用绑定，避免移动。 |
| `matches!(x, Some(_))` | 只判断是否匹配，返回 `bool`。 |
| `let Some(v) = opt else { return };` | let-else 提前退出。 |
| `if let` 链 | 多个条件用 `&&` 串联（Rust 2024 起支持）。 |

## trait

| 条目 | 说明 |
| --- | --- |
| `trait Greet { fn hi(&self) -> String; }` | 定义 trait，只写签名。 |
| `impl Greet for P { fn hi(&self) -> String { ... } }` | 为类型实现 trait，遵循孤儿规则。 |
| `trait Greet { fn hi(&self) -> String { "hi".into() } }` | 默认方法，实现者可覆盖。 |
| `trait Store { type Item; fn get(&self) -> Self::Item; }` | 关联类型，一个类型只能有一种实现。 |
| `trait Store { const MAX: usize = 8; }` | 关联常量。 |
| `trait Loud: Greet { }` | 父 trait（supertrait），实现者必须同时实现 `Greet`。 |
| `fn f(g: &dyn Greet)` | trait 对象，动态分发，走虚表。 |
| `fn f(g: impl Greet)` | 静态分发，泛型的语法糖。 |
| `Box<dyn Greet>` | 拥有所有权的 trait 对象，用于异构集合。 |
| `impl Greet for Vec<P> { }` | 可为泛型容器实现 trait。 |
| `#[derive(Debug)]` | 派生宏自动生成实现。 |

## 泛型与约束

| 条目 | 说明 |
| --- | --- |
| `fn f<T>(x: T) -> T { x }` | 泛型函数，单态化后零成本。 |
| `struct Wrap<T> { inner: T }` | 泛型结构体。 |
| `enum Either<L, R> { Left(L), Right(R) }` | 泛型枚举。 |
| `struct Buf<const N: usize>([u8; N]);` | const 泛型，长度参与类型。 |
| `fn f<T: Clone + Send>(x: T)` | 多重约束用 `+` 连接。 |
| `fn f<T>(x: T) where T: Clone { }` | `where` 子句，约束多时更易读。 |
| `impl<T: Display> Wrap<T> { }` | 条件实现，只对满足约束的 `T` 生效。 |
| `T: 'static` | 要求 `T` 不含非静态借用。 |
| `fn f<T: ?Sized>(x: &T)` | 放宽隐式的 `Sized` 约束。 |
| `impl<T> From<T> for Wrap<T> { }` | 泛型实现，做自动转换入口。 |

## 错误处理

| 条目 | 说明 |
| --- | --- |
| `Ok(v)` / `Err(e)` | 成功与失败分支，必须显式处理。 |
| `?` | 出错即 `return Err(From::from(e))`，可自动转换错误类型。 |
| `r.unwrap()` | 失败即 panic，只用于原型或不可能失败处。 |
| `r.expect("msg")` | 同 `unwrap`，但 panic 信息带上下文。 |
| `r.unwrap_or(default)` | 失败时使用备用值。 |
| `r.unwrap_or_else(\|e\| 0)` | 失败时用闭包计算备用值。 |
| `r.map(\|v\| v + 1)` | 只变换成功值。 |
| `r.map_err(\|e\| e.to_string())` | 只变换错误类型。 |
| `opt.ok_or(MyErr)?` | `Option` 转 `Result`，再交给 `?`。 |
| `impl From<io::Error> for MyErr { }` | 让 `?` 能自动转换，前提是实现 `From`。 |
| `Box<dyn std::error::Error>` | 一把梭的错误类型，适合应用层。 |
| `fn main() -> Result<(), Box<dyn Error>>` | `main` 也可返回 `Result`，失败时退出码非 0。 |

## 宏

| 条目 | 说明 |
| --- | --- |
| `println!("{}", x)` | 格式化打印到标准输出并换行。 |
| `format!("{x}-{y}")` | 返回 `String`，不打印。 |
| `vec![0; 3]` | 构造 `Vec`，`[值; 个数]` 形式。 |
| `assert_eq!(a, b)` | 断言相等，失败带两边值，需 `Debug`。 |
| `assert!(cond, "msg")` | 断言为真，失败 panic。 |
| `dbg!(&x)` | 打印表达式与值并原样返回，临时排查用。 |
| `matches!(x, Some(_))` | 模式匹配并返回 `bool`。 |
| `todo!()` / `unimplemented!()` | 占位并 panic，提醒未实现。 |
| `panic!("bad: {x}")` | 主动 panic，不可恢复错误的最后一招。 |
| `write!(buf, "{}", x)?` | 写入实现了 `fmt::Write` / `io::Write` 的目标。 |
| `macro_rules! sq { ($x:expr) => { $x * $x }; }` | 声明式宏，按片段匹配生成代码。 |
| `#[derive(Clone)]` | 派生宏，编译期生成 `impl`。 |

## 模块与可见性

| 条目 | 说明 |
| --- | --- |
| `mod math;` | 从 `math.rs` 或 `math/mod.rs` 引入子模块。 |
| `mod math { pub fn add() {} }` | 内联子模块，常写在测试或示例里。 |
| `pub fn add()` | 对外公开，父模块之外可见。 |
| `pub(crate) fn helper()` | 仅当前 crate 内可见。 |
| `pub(super) fn helper()` | 仅父模块可见。 |
| `fn private()` | 默认私有，是本模块及子模块的可见范围。 |
| `use crate::math::add;` | 绝对路径导入，`crate` 指当前 crate 根。 |
| `use super::add;` | `super` 指父模块，`self` 指当前模块。 |
| `use std::collections::HashMap as Map;` | 别名导入，避免重名。 |
| `use std::io::{self, Read};` | `self` 同时把模块自身导入。 |
| `pub use self::inner::add;` | 重导出，对外暴露更短的路径。 |
| `//! 模块文档` | 写在文件顶部的模块级文档注释。 |
| `/// 条目文档` | 写在条目上方的文档注释，会进 `cargo doc`。 |

## 最小可运行程序（把上面几块串起来）

```rust
trait Area {
    fn area(&self) -> f64;
}

#[derive(Debug)]
enum Shape {
    Rect { w: f64, h: f64 },
    Circle(f64),
}

impl Area for Shape {
    fn area(&self) -> f64 {
        match self {
            Shape::Rect { w, h } => w * h,
            Shape::Circle(r) => 3.14159 * r * r,
        }
    }
}

fn main() {
    let shapes = vec![Shape::Rect { w: 2.0, h: 3.0 }, Shape::Circle(1.0)];
    for s in &shapes {
        println!("{:?} -> {:.2}", s, s.area());
    }
    let total: f64 = shapes.iter().map(|s| s.area()).sum();
    println!("总面积 {:.2}", total);
}
```
