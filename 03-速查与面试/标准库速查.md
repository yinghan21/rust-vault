## `Option<T>`

条目页：[[option.Option|option.Option]] ｜ 手册：<https://doc.rust-lang.org/std/option/enum.Option.html>

| 方法 | 说明 |
| --- | --- |
| `is_some()` | 当是 `Some` 时返回 `true`。 |
| `is_none()` | 当是 `None` 时返回 `true`。 |
| `unwrap()` | 取出值，`None` 时 panic。 |
| `expect(msg)` | 取出值，`None` 时带 `msg` panic。 |
| `unwrap_or(d)` | 取出值，`None` 时返回 `d`。 |
| `unwrap_or_else(f)` | 取出值，`None` 时调用 `f` 生成默认值。 |
| `unwrap_or_default()` | 取出值，`None` 时返回 `T::default()`。 |
| `map(f)` | 只变换 `Some` 内的值。 |
| `and_then(f)` | 变换后返回新的 `Option`，用于串联可能失败的操作。 |
| `or(other)` | 自己为 `None` 时返回 `other`。 |
| `or_else(f)` | 自己为 `None` 时调用 `f` 生成备选。 |
| `filter(pred)` | 值不满足谓词时转为 `None`。 |
| `ok_or(err)` | 转换为 `Result`，`None` 映射为 `Err(err)`。 |
| `take()` | 取走值并把自身置为 `None`。 |
| `replace(v)` | 换入新值并返回旧值。 |
| `as_ref()` | 借出 `Option<&T>`，不移动原值。 |

配合 [[time.Instant|Instant]] 计时：

```rust
use std::time::{Duration, Instant};

fn main() {
    let start = Instant::now();
    let mut acc: u64 = 0;
    for i in 0..100_000u64 {
        acc = acc.wrapping_add(i);
    }
    let cost: Duration = start.elapsed();
    println!("{} 纳秒，累加结果 {}", cost.as_nanos(), acc);
}
```
