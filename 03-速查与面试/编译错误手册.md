# 编译错误手册

> [!abstract] 一句话
> 先按错误码定位，再看「原因」那一行是否说到点上，最后照「修复」块改写。

> [!tip] 查错的通用顺序
> 1. 从**第一个**错误开始修，后面的常是连锁反应；2. 先看「value moved here / borrowed here」这类位置提示；3. 用 `cargo check` 快速迭代，别等完整构建。

## E0382 · 借用已移动的值

| 项目 | 内容 |
| --- | --- |
| 现象 | `borrow of moved value: s1`，报在第二次使用处 |
| 原因 | `String` 等非 `Copy` 类型赋值、传参、入容器都是移动，原变量立即失效 |

最小复现：

```text
error[E0382]: borrow of moved value: `s1`
    let s1 = String::from("hi");
    let s2 = s1;                 // 所有权在这里移交给 s2
    println!("{}", s1);          // ❌ s1 已失效
```

修复（拷贝或改用借用）：

```rust
fn main() {
    let s1 = String::from("hi");
    let s2 = s1.clone(); // 显式深拷贝，两个变量都可用
    let n = s2.len(); // 或者只借用：let n = s2.len() 不需要移动
    println!("{} {} {}", s1, s2, n);
}
```

## E0502 · 可变借用与不可变借用冲突

| 项目 | 内容 |
| --- | --- |
| 现象 | `cannot borrow v as mutable because it is also borrowed as immutable` |
| 原因 | 不可变借用仍然存活时，又发起可变借用；引用活着就不能静默改变指向的数据 |

最小复现：

```text
error[E0502]: cannot borrow `v` as mutable because it is also borrowed as immutable
    let first = &v[0];
    v.push(4);                   // ❌ 可变借用与上面的不可变借用重叠
    println!("{}", first);       // 因为 first 在这里还要用
```

修复（先结束借用，再改）：

```rust
fn main() {
    let mut v = vec![1, 2, 3];
    {
        let first = &v[0];
        println!("{}", first);
    } // 不可变借用在此结束
    v.push(4);
    println!("{:?}", v);
}
```

## E0499 · 同时存在两个可变借用

| 项目 | 内容 |
| --- | --- |
| 现象 | `cannot borrow v as mutable more than once at a time` |
| 原因 | 可变借用必须独占；用于「别名 + 可变」的 `&mut` 不能有第二个 |

最小复现：

```text
error[E0499]: cannot borrow `v` as mutable more than once at a time
    let a = &mut v;
    let b = &mut v;              // ❌ 第二个可变借用
    a.push(1);
    b.push(2);
```

修复（分段借用，或用 `split_at_mut` 拿两块不重叠的 `&mut`）：

```rust
fn main() {
    let mut v = vec![1, 2, 3, 4];
    let (left, right) = v.split_at_mut(2);
    left[0] = 10;
    right[0] = 20;
    println!("{:?}", v);
}
```

## E0505 · 被借用期间不能移动

| 项目 | 内容 |
| --- | --- |
| 现象 | `cannot move out of s because it is borrowed` |
| 原因 | 移动会让引用指向已失效的位置，所以借用未结束时禁止移动 |

最小复现：

```text
error[E0505]: cannot move out of `s` because it is borrowed
    let r = &s;
    let t = s;                   // ❌ r 还活着
    println!("{}", r);
```

修复（先让借用结束，再移动）：

```rust
fn main() {
    let s = String::from("hi");
    let r = &s;
    println!("{}", r); // 借用的最后一次使用
    let t = s; // 之后才允许移动
    println!("{}", t);
}
```

## E0503 · 被可变借用期间读取原值

| 项目 | 内容 |
| --- | --- |
| 现象 | `cannot use s because it was mutably borrowed` |
| 原因 | 存在 `&mut` 时，原值既不能读也不能写，一切访问都得走那个可变引用 |

最小复现：

```text
error[E0503]: cannot use `s` because it was mutably borrowed
    let r = &mut s;
    println!("{}", s);           // ❌ 通过 r 借用期间直接读 s
    r.push('!');
```

修复（重排顺序，先取出需要的值再改）：

```rust
fn main() {
    let mut s = String::from("hi");
    let n = s.len(); // 先在可变借用之前算好
    s.push('!');
    println!("{} {}", n, s);
}
```

## E0596 · 不能可变借用未标 mut 的变量

| 项目 | 内容 |
| --- | --- |
| 现象 | `cannot borrow v as mutable, as it is not declared as mutable` |
| 原因 | 绑定默认不可变，可变性属于**绑定**而不是类型 |

最小复现：

```text
error[E0596]: cannot borrow `v` as mutable, as it is not declared as mutable
    let v = vec![1];
    v.push(2);                   // ❌ 需要 let mut v
```

修复：

```rust
fn main() {
    let mut v = vec![1];
    v.push(2);
    println!("{:?}", v);
}
```

## E0597 · 借用的值活不够久

| 项目 | 内容 |
| --- | --- |
| 现象 | `x does not live long enough`，提示 `borrowed value does not live long enough` |
| 原因 | 引用比它指向的值活得久，出借用作用域后引用就悬垂 |

最小复现：

```text
error[E0597]: `x` does not live long enough
    let r;
    {
        let x = 5;
        r = &x;                  // ❌ x 在本块结束时被释放
    }
    println!("{}", r);
```

修复（让被借用者活得更久）：

```rust
fn main() {
    let x = 5;
    let r = &x;
    println!("{}", r);
}
```

## E0716 · 临时值在借用结束前被释放

| 项目 | 内容 |
| --- | --- |
| 现象 | `temporary value dropped while borrowed` |
| 原因 | 借用直接挂在临时表达式上，语句结束临时值就被 drop |

最小复现：

```text
error[E0716]: temporary value dropped while borrowed
    let r = String::from("hi").as_str();   // ❌ String 在语句末被释放
    println!("{}", r);
```

修复（先把临时值绑定成变量）：

```rust
fn main() {
    let owned = String::from("hi");
    let r = owned.as_str(); // 借用挂在具名变量上
    println!("{}", r);
}
```

## E0515 · 不能返回指向局部变量的引用

| 项目 | 内容 |
| --- | --- |
| 现象 | `returns a value referencing data owned by the current function` |
| 原因 | 局部变量在函数返回时被释放，返回给调用方就是悬垂引用 |

最小复现：

```text
error[E0515]: cannot return reference to local variable `s`
fn make() -> &str {
    let s = String::from("hi");
    &s                           // ❌ s 随函数结束一起释放
}
```

修复（返回拥有所有权的值，或返回 `'static` 字面量）：

```rust
fn make() -> String {
    String::from("hi")
}

fn main() {
    println!("{}", make());
}
```

## E0106 · 缺少生命周期标注

| 项目 | 内容 |
| --- | --- |
| 现象 | `missing lifetime specifier`，提示 `expected named lifetime parameter` |
| 原因 | 返回引用有多个可能的来源，编译器无法判断它借自哪个参数 |

最小复现：

```text
error[E0106]: missing lifetime specifier
fn longest(a: &str, b: &str) -> &str {   // ❌ 返回值可能来自 a，也可能来自 b
    if a.len() >= b.len() { a } else { b }
}
```

修复（显式声明输出借用与输入同寿）：

```rust
fn longest<'a>(a: &'a str, b: &'a str) -> &'a str {
    if a.len() >= b.len() {
        a
    } else {
        b
    }
}

fn main() {
    println!("{}", longest("abc", "de"));
}
```

## E0277 · trait 约束不满足

| 项目 | 内容 |
| --- | --- |
| 现象 | `the trait bound ... is not satisfied`，常附带 `the trait Display is not implemented` |
| 原因 | 用到了某个类型没实现的能力，例如对 `Vec` 用 `{}` 打印 |

最小复现：

```text
error[E0277]: `Vec<{integer}>` doesn't implement `std::fmt::Display`
    let v = vec![1, 2, 3];
    println!("{}", v);           // ❌ Vec 只实现了 Debug
```

修复（换用 `{:?}` 或补上 trait 实现）：

```rust
fn main() {
    let v = vec![1, 2, 3];
    println!("{:?}", v); // Debug 版占位符
}
```

## E0308 · 类型不匹配

| 项目 | 内容 |
| --- | --- |
| 现象 | `mismatched types`，附 `expected i32, found &str` |
| 原因 | 两侧类型不同且没有自动转换；Rust 不做隐式类型转换 |

最小复现：

```text
error[E0308]: mismatched types
    let x: i32 = "42";           // ❌ expected `i32`, found `&str`
    let y: u64 = 1;              // 与 let z: u32 = y; 也是同类错误
```

修复（显式解析或显式转换）：

```rust
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let x: i32 = "42".parse()?; // 走 FromStr
    let y: u64 = 1;
    let z: u32 = y as u32; // 明确写出有损转换
    println!("{} {}", x, z);
    Ok(())
}
```

## E0369 · 二元运算符不支持该类型

| 项目 | 内容 |
| --- | --- |
| 现象 | `cannot add String to {integer}` 或 `binary operation ... cannot be applied` |
| 原因 | 运算符是 trait 语法糖，`Add`/`Sub` 等没有为该类型组合实现 |

最小复现：

```text
error[E0369]: cannot add `{integer}` to `String`
    let s = String::from("n=");
    let r = s + 1;               // ❌ String 只实现了 Add<&str>
```

修复（用 `format!` 拼接，或显式转成字符串）：

```rust
fn main() {
    let s = String::from("n=");
    let r = format!("{}{}", s, 1);
    let also = s + "1"; // String + &str 是允许的
    println!("{} {}", r, also);
}
```

## E0433 · 路径无法解析

| 项目 | 内容 |
| --- | --- |
| 现象 | `failed to resolve: use of undeclared crate or module serde` |
| 原因 | 路径的根不存在：依赖没加进 `Cargo.toml`、模块没声明、或路径写错 |

最小复现：

```text
error[E0433]: failed to resolve: use of undeclared crate or module `serde`
use serde::Serialize;            // ❌ Cargo.toml 里没有 serde 依赖
```

修复（用标准库路径，或先 `cargo add`）：

```rust
use std::collections::HashMap;

fn main() {
    let mut m: HashMap<&str, i32> = HashMap::new();
    m.insert("a", 1);
    println!("{:?}", m);
}
```

## E0425 · 作用域里找不到这个名字

| 项目 | 内容 |
| --- | --- |
| 现象 | `cannot find value x in this scope` |
| 原因 | 变量定义在内层块，出了块就不存在；也可能是拼写或提前使用 |

最小复现：

```text
error[E0425]: cannot find value `total` in this scope
    for i in 1..=3 {
        let total = i;           // ❌ 只在循环体里存在
    }
    println!("{}", total);
```

修复（把累加变量提到外层作用域）：

```rust
fn main() {
    let mut total = 0;
    for i in 1..=3 {
        total += i;
    }
    println!("{}", total);
}
```

## E0599 · 该类型没有这个方法

| 项目 | 内容 |
| --- | --- |
| 现象 | `no method named push_str found for reference &str`，常附 `items from traits can only be used if the trait is in scope` |
| 原因 | 方法来自另一个类型，或 trait 未 `use` 进作用域 |

最小复现：

```text
error[E0599]: no method named `push_str` found for type `&str`
    let mut s: &str = "a";
    s.push_str("b");             // ❌ &str 不可增长，push_str 是 String 的方法
```

修复（换成 `String`，或把 trait 引入作用域）：

```rust
fn main() {
    let mut s = String::from("a");
    s.push_str("b");
    println!("{}", s);
}
```

## E0061 · 参数个数不对

| 项目 | 内容 |
| --- | --- |
| 现象 | `this function takes 1 argument but 0 arguments were supplied` |
| 原因 | 调用时漏参/多参；Rust 没有默认参数与重载 |

最小复现：

```text
error[E0061]: this method takes 1 argument but 0 arguments were supplied
    let s = "a b c";
    let it = s.split();          // ❌ split 需要一个分隔模式
```

修复（补上分隔符，或改用无参方法）：

```rust
fn main() {
    let s = "a b c";
    let parts: Vec<&str> = s.split_whitespace().collect();
    let by_char: Vec<&str> = s.split(' ').collect();
    println!("{:?} {:?}", parts, by_char);
}
```

## E0507 · 不能从借用内容中移动出来

| 项目 | 内容 |
| --- | --- |
| 现象 | `cannot move out of index of Vec<String>` 或 `cannot move out of borrowed content` |
| 原因 | 手上的只是 `&T`，没有所有权，不能把里面的字段带走 |

最小复现：

```text
error[E0507]: cannot move out of index of `Vec<String>`
fn first(v: &Vec<String>) -> String {
    v[0]                         // ❌ 只能拿到 &String，不能直接移动
}
```

修复（克隆、取引用，或用 `std::mem::take` 换走）：

```rust
fn first(v: &[String]) -> String {
    v[0].clone()
}

fn main() {
    let v = vec![String::from("a")];
    println!("{}", first(&v));
}
```

## E0658 · 使用了未稳定的特性

| 项目 | 内容 |
| --- | --- |
| 现象 | `use of unstable library feature`，提示 `add #![feature(...)] to the crate attributes` |
| 原因 | 该 API 还在 nightly 阶段，stable 编译器默认拒绝 |

最小复现：

```text
error[E0658]: use of unstable library feature `iter_map_windows`
    let pairs: Vec<_> = v.iter().map_windows(|w: &&[i32; 2]| (w[0], w[1])).collect();
```

修复（用稳定写法等价实现）：

```rust
fn main() {
    let v = vec![1, 2, 3, 4];
    let pairs: Vec<(i32, i32)> = v.windows(2).map(|w| (w[0], w[1])).collect();
    println!("{:?}", pairs);
}
```

## E0603 · 模块或条目是私有的

| 项目 | 内容 |
| --- | --- |
| 现象 | `module inner is private`，或 `function hello is private` |
| 原因 | 默认可见性只在当前模块及子模块内；跨模块访问需要 `pub` |

最小复现：

```text
error[E0603]: module `inner` is private
mod outer {
    mod inner {                  // ❌ 没有 pub
        pub fn hello() {}
    }
}
fn main() { outer::inner::hello(); }
```

修复（逐层补齐 `pub`）：

```rust
mod outer {
    pub mod inner {
        pub fn hello() -> &'static str {
            "hi"
        }
    }
}

fn main() {
    println!("{}", outer::inner::hello());
}
```

## 查错速记

| 错误码 | 一句话 |
| --- | --- |
| E0382 | 值被移动后还在用，`clone` 或改成借用。 |
| E0502 | 读写借用重叠，缩小借用作用域。 |
| E0499 | 两个 `&mut`，分段或用 `split_at_mut`。 |
| E0505 | 借用期间移动，先让引用退休。 |
| E0503 | `&mut` 期间直接访问原值，重排语句。 |
| E0596 | 忘了 `let mut`。 |
| E0597 | 引用比数据活得久，调整声明位置。 |
| E0716 | 借用挂在临时值上，先绑定变量。 |
| E0515 | 返回局部变量的引用，改返回所有权。 |
| E0106 | 返回引用缺生命周期标注。 |
| E0277 | 缺 trait 实现，换占位符或补 `impl`。 |
| E0308 | 类型不符，`as`/`parse`/`into` 显式转换。 |
| E0369 | 运算符缺实现，改 `format!` 等。 |
| E0433 | 路径根不存在，查依赖与 `mod` 声明。 |
| E0425 | 变量不在作用域，检查块范围与拼写。 |
| E0599 | 方法不存在，类型不对或 trait 没 `use`。 |
| E0061 | 参数个数不对，Rust 无默认参数。 |
| E0507 | 从借用里移动，`clone` 或 `mem::take`。 |
| E0658 | 用到 nightly 特性，换稳定写法。 |
| E0603 | 可见性不足，补 `pub`/`pub(crate)`。 |
