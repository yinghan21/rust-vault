# 术语表

> [!tip] 用法
> 阅读英文文档或报错时按 `Ctrl+F` 查这里；`Ctrl+O` 可直接跳到对应笔记。

## 所有权与借用

| 英文 | 中文 | 说明 |
| --- | --- | --- |
| ownership | 所有权 | 每个值有唯一所有者，所有者离开作用域时值被释放。 |
| owner | 所有者 | 负责释放某个值的变量。 |
| move | 移动 | 把所有权转交给另一个变量，原变量失效。 |
| copy | 复制 | 按位复制，原变量仍然有效（要求实现 `Copy`）。 |
| clone | 克隆 | 显式深拷贝，通常伴随堆分配。 |
| borrow | 借用 | 通过引用访问值而不取得所有权。 |
| borrow checker | 借用检查器 | 编译期检查引用合法性的组件。 |
| mutable borrow | 可变借用 | `&mut T`，同一时刻只能有一个，且不能与共享借用共存。 |
| shared borrow | 共享借用 | `&T`，可以同时存在多个。 |
| dangling pointer | 悬垂指针 | 指向已释放内存的指针，Rust 在安全代码中禁止。 |
| lifetime | 生命周期 | 引用有效的作用域范围，写作 `'a`。 |
| drop | 丢弃/析构 | 值离开作用域时自动调用的清理逻辑。 |

## 类型与抽象

| 英文 | 中文 | 说明 |
| --- | --- | --- |
| trait | 特质 | 定义一组方法签名，类似接口，但可带默认实现。 |
| trait object | 特质对象 | `dyn Trait`，运行期动态分发。 |
| generic | 泛型 | 用类型参数编写可复用的代码，编译期单态化。 |
| monomorphization | 单态化 | 编译器为每个具体类型生成一份代码。 |
| associated type | 关联类型 | trait 中的类型占位符，如 `Iterator::Item`。 |
| associated function | 关联函数 | `impl` 块中不带 `self` 的函数，如 `String::new()`。 |
| method | 方法 | 第一个参数是 `self`/`&self`/`&mut self` 的函数。 |
| orphan rule | 孤儿规则 | 只能为「本地类型」或「本地 trait」实现，不能两者都外部。 |
| coherence | 一致性 | 保证 trait 实现不冲突的规则集合。 |
| blanket impl | 毯式实现 | 为满足约束的所有类型统一实现 trait，如 `impl<T> ToString for T`。 |
| marker trait | 标记特质 | 没有方法的 trait，如 `Send`、`Sync`、`Copy`。 |
| auto trait | 自动特质 | 编译器自动推导的 trait，如 `Send`、`Sync`。 |
| dyn compatibility | dyn 兼容性 | 旧称 object safety，决定 trait 能否作为 `dyn Trait` 使用。 |
| turbofish | 涡轮鱼语法 | 显式指定泛型参数的写法：`parse::<i32>()`。 |

## 内存与安全

| 英文 | 中文 | 说明 |
| --- | --- | --- |
| stack | 栈 | 存放局部变量，自动分配释放，速度快。 |
| heap | 堆 | 动态分配内存，通过 `Box`/`Vec`/`String` 等使用。 |
| unsafe | 不安全代码 | 允许裸指针、调用外部函数等，需自己保证内存安全。 |
| undefined behavior | 未定义行为 | 编译器不保证结果的行为，必须避免。 |
| aliasing | 别名 | 多个引用指向同一内存；可变别名是 UB 的来源之一。 |
| interior mutability | 内部可变性 | 通过 `Cell`/`RefCell`/`Mutex` 在共享引用下修改数据。 |
| RAII | 资源获取即初始化 | 用构造函数获取资源、析构函数释放资源。 |
| zero-cost abstraction | 零成本抽象 | 抽象不带来运行时开销，如迭代器。 |

## 并发与异步

| 英文 | 中文 | 说明 |
| --- | --- | --- |
| thread | 线程 | 操作系统线程，`std::thread`。 |
| channel | 通道 | 线程间传递消息，`std::sync::mpsc`。 |
| mutex | 互斥锁 | 同一时刻只允许一个线程访问数据。 |
| atomic | 原子类型 | 无锁的整数/布尔操作，`std::sync::atomic`。 |
| `Send` | 可发送 | 类型可以跨线程转移所有权。 |
| `Sync` | 可共享 | 类型的 `&T` 可以跨线程共享。 |
| future | 未来值 | 异步计算的占位符，需被 executor 轮询。 |
| executor | 执行器 | 驱动 `Future` 运行，如 `tokio` 运行时。 |
| poll | 轮询 | executor 推进 `Future` 的方式。 |
| waker | 唤醒器 | `Future` 就绪时通知 executor 的机制。 |

## 工程与工具

| 英文 | 中文 | 说明 |
| --- | --- | --- |
| crate | 包/库 | Rust 的编译单元，分二进制与库两种。 |
| module | 模块 | 用 `mod` 组织的命名空间。 |
| workspace | 工作区 | 多个 crate 共享 `Cargo.lock` 与构建目录。 |
| feature | 特性 | Cargo 的条件编译开关。 |
| edition | 版次 | 语言版本（2015/2018/2021/2024），按 crate 指定。 |
| macro | 宏 | 编译期代码生成，分声明宏与过程宏。 |
| lint | 检查项 | 编译器的警告/错误规则，如 `dead_code`。 |
| monomorphization | 单态化 | 见上，泛型的实现方式。 |
| doctest | 文档测试 | 文档注释中的代码块会被当作测试运行。 |
| MSRV | 最低支持版本 | Minimum Supported Rust Version。 |
