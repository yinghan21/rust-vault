# 如何使用这个库

## 1. 用 Obsidian 打开

1. 安装 [Obsidian](https://obsidian.md/)（免费）。
2. 启动后选择「**打开文件夹作为仓库**」（Open folder as vault）。
3. 选择 `Rust学习宝库` 文件夹，信任并打开。
4. 首次打开会在右下角提示「信任作者并启用插件」——本库只用了核心插件，**不需要安装任何第三方插件**。

打开后默认显示 [[首页]]（如果没自动打开，在文件列表里点它一下）。

## 2. 推荐打开的视图

| 功能 | 位置 | 用途 |
| --- | --- | --- |
| 关系图 | 左侧栏「关系图」 | 看笔记之间的连接，颜色按标签分组 |
| 标签面板 | 左侧栏「标签」 | 按 `rust/基础`、`std/类型` 筛选 |
| 反向链接 | 右侧栏「反向链接」 | 看哪些笔记引用了当前笔记 |
| 大纲 | 右侧栏「大纲」 | 长笔记内快速跳转 |
| 全局搜索 | `Ctrl+Shift+F` | 搜代码、搜 API |

> [!tip] 搜索语法
> - `tag:#std/类型`：按标签过滤
> - `path:10-标准库std/集合`：限定目录
> - `file:HashMap`：按文件名
> - `line:(mut borrow)`：按行内容

## 3. 三种阅读路径

- **线性学习**：[[学习路线]] → 基础 → 进阶 → 项目。
- **查 API**：[[模块索引]] → 模块页 → 条目页；或 [[标准库速查]]。
- **按问题查**：[[编译错误手册]]（报错码）→ [[常见陷阱]]（行为陷阱）→ [[面试题]]。

## 4. 笔记之间的约定

- 蓝色双链 `[[...]]` 都是本库内的笔记，点击即跳转。
- std 条目页文件名形如 `option.Option.md`、`collections.HashMap.md`，链接一般显示短名（`Option`、`HashMap`）。
- 每篇 std 条目页底部有「相关」，可回到模块页或相关学习笔记。
- 模块页末尾的「全部条目」表格由脚本生成，包含该模块所有条目的官方文档链接。

## 5. 新增自己的笔记

1. 在 `90-模板` 里复制 [[模板-学习笔记]] 或 [[模板-标准库条目]] 到目标目录。
2. 改 frontmatter 的 `title`、`tags`、`aliases`、`一句话`。
3. 正文按模板小节填写；链接用 `[[目标笔记|显示文字]]`。
4. 如果你装了 Templates 核心插件，也可以直接 `Ctrl+P` →「插入模板」。

> [!warning] 不要修改自动生成区块
> 模块页末尾「全部条目」位于 `<!-- BEGIN AUTO ITEMS -->` 与 `<!-- END AUTO ITEMS -->` 之间，重新生成时会被覆盖。

## 6. 同步与备份

- 整个库就是一堆 Markdown 文件，可以直接用 Git、OneDrive、iCloud 同步。
- 建议 `git init` 后定期提交；`.obsidian/workspace.json` 可以忽略。
- 图片等附件放在 `99-附件`。

## 7. 这个库是怎么做出来的

- 学习笔记：按中文教材思路重写，示例都可独立编译。
- 标准库部分：模块/条目/方法签名从本地 rustdoc（Rust 1.99.1）提取，中文说明按原文整理，稳定版本号来自官方标注。
- 自动校验：所有 `rust` 代码块会逐个用 `rustc` 编译检查，内部链接会检查是否存在。
