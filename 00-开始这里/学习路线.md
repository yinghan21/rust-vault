# Rust 学习路线

> [!abstract] 怎么用
> 从上往下走，每个阶段完成后勾掉检查项。**不要跳阶段**：所有权没搞懂就学异步，会反复卡住。

## 阶段 0 · 前置知识（半天）

- 会用命令行（`cd`、`ls`、环境变量）。
- 知道什么是编译型语言、栈与堆的区别。
- 有任意一门语言的编程经验即可（C/C++/Go/Java/Python 都行）。

## 阶段 1 · 入门（1–2 周）

**目标**：能写几十行的小程序，理解「值、所有权、借用」三件事。

- [ ] [[01-安装与工具链]]：装好 `rustup`、`rustc`、`cargo`，跑通 `hello world`。
- [ ] [[02-Cargo 与项目结构]]：会建库/二进制项目，看懂 `Cargo.toml`。
- [ ] [[03-变量与数据类型]]：`let`、`mut`、标量与复合类型、类型推断。
- [ ] [[04-函数与控制流]]：函数、`if`、`loop`/`while`/`for`、表达式返回值。
- [ ] [[05-所有权]]：move、clone、Copy。
- [ ] [[06-借用与引用]]：`&T` / `&mut T`、借用规则。
- [ ] [[11-错误处理]] 前半：`panic!`、`Result`、`?`。

**验收**：写一个「猜数字」或「单词计数」命令行程序，能用 `Result` 处理错误。

**练习**：把 [[05-所有权]] 的 3 道练习做完；在 [rustlings](https://github.com/rust-lang/rustlings) 完成 `variables`～`move_semantics`。

## 阶段 2 · 基础（3–4 周）

**目标**：能用结构体、枚举、trait 组织代码，熟练使用集合与字符串。

- [ ] [[07-结构体]]：字段、元组结构体、`impl` 与关联函数。
- [ ] [[08-枚举与模式匹配]]：`Option`、`match`、`if let`、`while let`。
- [ ] [[09-方法与 impl]]：`self`、`&self`、`&mut self`、关联函数。
- [ ] [[10-模块与可见性]]：`mod`、`pub`、`use`、工作区。
- [ ] [[11-错误处理]]：自定义错误、`Box<dyn Error>`、`thiserror`/`anyhow` 的位置。
- [ ] [[12-集合类型]]：`Vec`、`HashMap`、`BTreeMap`、`VecDeque` 的取舍。
- [ ] [[13-字符串]]：`String` 与 `&str`、UTF-8、拼接与切片。
- [ ] [[14-泛型]]：泛型函数/结构体、trait 约束。
- [ ] [[15-trait 基础]]：定义、实现、默认方法、孤儿规则。
- [ ] [[25-测试与文档]]：`#[test]`、`assert_eq!`、文档测试。
- [ ] [[模块索引]]：把 `std::collections`、`std::option`、`std::result` 翻一遍。

**验收**：实现一个带错误类型的「CSV 统计工具」或「TODO 管理器」，有单元测试。

## 阶段 3 · 进阶（4–6 周）

**目标**：理解零成本抽象的实现方式，能写并发程序，读懂常见的泛型签名。

- [ ] [[17-生命周期]]：`'a`、省略规则、结构体中的引用。
- [ ] [[18-迭代器]]：惰性、适配器、`collect`、自定义迭代器。
- [ ] [[19-闭包]]：`Fn`/`FnMut`/`FnOnce`、捕获方式、`move`。
- [ ] [[20-智能指针]]：`Box`、`Rc`/`Arc`、`RefCell`、`Deref`。
- [ ] [[21-并发编程]]：`thread`、`mpsc`、`Mutex`/`RwLock`、`Send`/`Sync`。
- [ ] [[16-trait 对象与动态分发]]：`dyn Trait`、对象安全、静态 vs 动态分发。
- [ ] [[22-异步编程]]：`async`/`await`、`Future`、`tokio` 入门。
- [ ] [[23-宏]]：`macro_rules!`、常用内置宏、过程宏概览。
- [ ] [[24-unsafe 与 FFI]]：裸指针、`unsafe` 的边界、调用 C。
- [ ] [[26-性能与优化]]：`Vec` 扩容、`with_capacity`、避免不必要的 `clone`。
- [ ] [[27-常用 crate 与生态]]：`serde`、`clap`、`rand`、`regex`、`tracing`。

**验收**：写一个多线程下载器或并发单词统计，能解释每一处 `Arc<Mutex<T>>` 的必要性。

## 阶段 4 · 实战（持续）

- [ ] [[01-命令行工具]]：`clap` + 文件处理，发布到 crates.io。
- [ ] [[02-Web API 服务]]：`axum`/`actix-web` + `serde` + 错误处理。
- [ ] [[03-并发爬虫]]：`reqwest` + `tokio` + 限流。
- [ ] [[04-WASM 前端]]：`wasm-bindgen`。
- [ ] [[05-嵌入式入门]]：`no_std`、`embedded-hal`。

## 每周节奏建议

| 时间 | 内容 |
| --- | --- |
| 2 h | 读一篇笔记 + 敲一遍示例 |
| 3 h | 做对应练习/小项目 |
| 1 h | 回看 [[编译错误手册]]，整理自己踩的坑 |

## 学完之后

- 读《The Rust Programming Language》对应章节查漏补缺。
- 读 [Rust 死灵书](https://doc.rust-lang.org/nomicon/) 理解 `unsafe` 的边界。
- 参与一个开源项目，从 `good first issue` 开始。

> [!tip] 卡住时
> 先看 [[常见陷阱]] 和 [[编译错误手册]]；再回到 [[05-所有权]]、[[06-借用与引用]]、[[17-生命周期]] 三篇。
