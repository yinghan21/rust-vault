# 🦀 Rust 学习宝库

一个中文 Rust 知识库，配套一份**标准库 `std` 中文参考**。全部内容为 Markdown，用 [Obsidian](https://obsidian.md/) 打开即可获得双链、关系图、标签与全文搜索。

> [!tip] 在 GitHub 上阅读
> GitHub 不会渲染 Obsidian 双链和 `> [!note]` 提示块：`[[option.Option|Option]]` 会显示成普通文字，提示块会多出 `[!note]` 字样。想看完整效果，请克隆后按下面的「打开方式」用 Obsidian 打开；只查内容的话，从 `10-标准库std/01-模块索引.md` 或各目录的 Markdown 文件点进去即可。

## 打开方式

1. 安装 Obsidian。
2. 「打开文件夹作为仓库」→ 选择本目录。
3. 从 [[首页]] 开始；或按 `Ctrl+O` 搜索。

详细操作见 [[如何使用这个库]]。

## 里面有什么

| 模块 | 内容 | 篇数 |
| --- | --- | --- |
| 00 开始这里 | 首页、学习路线、术语表、使用说明 | 4 |
| 01 Rust 语言 | 入门 13 篇 + 进阶 14 篇，覆盖所有权到异步/宏/unsafe | 27 |
| 02 实战项目 | 命令行、Web API、并发爬虫、WASM、嵌入式 | 5 |
| 03 速查与面试 | 语法/标准库/Cargo 速查、编译错误手册、陷阱、面试题 | 6 |
| 10 标准库 std | 78 个模块页 + 108 个核心条目页（含中文方法表） | 186 |

- **模块页**：每个 `std` 模块的中文简介、快速上手、常用条目、注意事项；文末自动附**全部公开条目**索引（含官方文档链接）。
- **条目页**：`Option`、`Result`、`Vec`、`String`、`HashMap`、`Iterator`、`File`、`Mutex`…… 提供按功能分组的中文方法表、可运行示例、常见陷阱与相关链接。
- 方法签名与稳定版本号提取自本机 **Rust 1.99.1** 的官方 rustdoc，只收录稳定 API（nightly/已弃用不计入方法表）。

## 质量校验

- 全部内部 `[[链接]]` 均指向真实笔记（0 断链）。
- 458 个 `rust` 代码块逐个用 `rustc --edition 2021` 编译校验（异步/项目页中依赖 tokio 等的示例单独标注）。
- 每篇笔记都有统一 frontmatter（标题、类型、标签、别名、一句话），支持按 `rust/基础`、`std/类型` 等标签检索。

## 约定
